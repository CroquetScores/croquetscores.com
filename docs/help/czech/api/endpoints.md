# Koncové body API

Každá adresa je pod `/api/v1` na webu a každá odpověď je JSON. Co platí pro všechny, jako klíče, limity, chyby a levné dotazování, je v [nápovědě pro vývojáře aplikací](index.md).

Jsou dva druhy a každý má svou stránku:

- [Koncové body pro GET](get-endpoints.md) čtou: turnaje jednoho roku, turnaj, soutěž, její tabulku a hry, sporty, formáty a země, čím může turnaj být, hráče světového žebříčku a jejich hry, co klíč smí, a co se změnilo nebo bylo archivováno.
- [Koncové body pro POST](post-endpoints.md) něco mění: vytvoření turnaje, jeho soutěží, hráčů, týmů a her a to, kdo ho smí řídit a zapisovat.
