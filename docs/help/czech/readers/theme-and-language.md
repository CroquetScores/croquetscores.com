# Volba motivu a jazyka

Obě volby jsou na konci každé stránky a obě se pamatují, takže je uděláte jednou.

## Motiv

**Motiv** nabízí **Světlý**, **Tmavý** a **Systémový**. **Systémový**, což máte, dokud nezvolíte, se řídí vaším telefonem nebo počítačem: web je tmavý, když je tmavé zařízení, a světlý, když není. Zvolte **Světlý** nebo **Tmavý** a web bude takový, ať zařízení dělá cokoli.

## Jazyk

Dokud nezvolíte, web mluví prvním jazykem, který podle vašeho prohlížeče čtete a který web má. Pokud nemá žádný z nich, mluví anglicky.

Chcete-li zvolit jiný, vyberte ho v seznamu **Jazyk** a stiskněte **Změnit**. Stránka se vrátí v tomto jazyce a stejně tak každá další, při této návštěvě i při příští. Seznam se otevře na jazyku, v němž čtete.

Stránka této nápovědy, která ještě nebyla přeložena do vašeho jazyka, se zobrazí anglicky, místo aby se nezobrazila vůbec.

## Pokud se volba zapomene

Web si každou volbu pamatuje v cookie, takže prohlížeč, který cookies maže nebo je nemá uchovávat, zapomene a požádá vás, abyste zvolili znovu. [Skriptování a cookies](scripting-and-cookies.md) říká, co web uchovává.

Další: [Skriptování a cookies](scripting-and-cookies.md).
