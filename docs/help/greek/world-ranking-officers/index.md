# Βοήθεια για υπευθύνους παγκόσμιας κατάταξης

Ένας υπεύθυνος παγκόσμιας κατάταξης φροντίζει τις παγκόσμιες κατατάξεις ενός ή περισσότερων αθλημάτων. Έχετε στη διαχείριση ό,τι έχει κάθε συνδεδεμένος αναγνώστης: μπορείτε να δημιουργήσετε ένα τουρνουά και να διαχειριστείτε ή να καταχωρίσετε αποτελέσματα στα τουρνουά στα οποία σας έχουν κάνει υπεύθυνο ή καταχωρητή, όπως οι [υπεύθυνοι τουρνουά](../tournament-managers/index.md). Αυτή η σελίδα λέει μόνο τι σας δίνεται επιπλέον, στη λίστα τουρνουά στο `/admin` και στην ίδια λίστα για άλλη χρονιά στο `/admin/2025`, `/admin/2024` κ.ο.κ.

## Κάθε τουρνουά των αθλημάτων σας

Η λίστα σας περιέχει κάθε τουρνουά των αθλημάτων που φροντίζετε, όποιος και αν το διοργανώνει, καθώς και τα τουρνουά που διαχειρίζεστε ή στα οποία καταχωρίζετε αποτελέσματα. Αυτό είναι περισσότερο από όσο θα θέλατε να διαβάσετε, γι' αυτό η λίστα μπορεί να περιοριστεί, όπως περιγράφεται παρακάτω.

Οι χρονιές που σας προσφέρονται είναι οι χρονιές στις οποίες ξεκινούν αυτά τα τουρνουά, καθώς και οι χρονιές των δικών σας. Επιλέξτε μία από τις καρτέλες στο πάνω μέρος ή τις **Προηγούμενες χρονιές** για τις υπόλοιπες και η λίστα είναι αυτής της χρονιάς. Το `/admin` είναι η φετινή χρονιά.

## Περιορισμός της λίστας

Δίπλα στο **Νέο τουρνουά** υπάρχουν τρία κουμπιά κάτω από την ετικέτα **Εμφάνιση**:

- Το **Υπεύθυνος/Καταχωρητής** παραθέτει τα τουρνουά που διαχειρίζεστε ή στα οποία καταχωρίζετε αποτελέσματα.
- Η **Παγκόσμια κατάταξη** παραθέτει τα τουρνουά με ένα αγώνισμα που μετράει για τις παγκόσμιες κατατάξεις.
- Η **Εκτός παγκόσμιας κατάταξης** παραθέτει τα τουρνουά που δεν έχουν κανένα.

Ένα κουμπί που είναι ενεργό έχει ένα τικ. Ένα τουρνουά παρατίθεται όταν είναι ενεργό οποιοδήποτε κουμπί που του ταιριάζει, γι' αυτό κάθε κουμπί προσθέτει τουρνουά στη λίστα και κανένα δεν αφαιρεί. Το **Υπεύθυνος/Καταχωρητής** και η **Παγκόσμια κατάταξη** είναι ενεργά στην αρχή και η **Εκτός παγκόσμιας κατάταξης** είναι ανενεργή, γι' αυτό ξεκινάτε με τα τουρνουά που διοργανώνετε και αυτά από τα οποία φτιάχνονται οι κατατάξεις, και πατάτε **Εκτός παγκόσμιας κατάταξης** για να διαβάσετε τα υπόλοιπα.

Αν απενεργοποιήσετε κάθε κουμπί, η λίστα είναι άδεια και λέει ότι κανένα τουρνουά δεν ταιριάζει και τα κουμπιά μένουν, ώστε να μπορείτε να ενεργοποιήσετε ξανά ένα.

Τα κουμπιά γράφονται στη διεύθυνση της σελίδας, γι' αυτό το κουμπί πίσω αναιρεί το τελευταίο που πατήσατε και μια διεύθυνση που αντιγράφετε δείχνει τη λίστα όπως την είχατε. Εμφανίζονται μόνο όταν υπάρχει λίστα να περιοριστεί, γι' αυτό μια χρονιά χωρίς τουρνουά δεν έχει.

Κάτω από αυτά οι λίστες **Χώρα**, **Περιοχή** και **Άθλημα** περιορίζουν ό,τι άφησαν τα κουμπιά, όπως για όλους. Προσφέρουν μόνο ό,τι υπάρχει σε αυτή τη λίστα, γι' αυτό μια επιλογή δεν σας δίνει ποτέ τίποτα.

## Τι μπορείτε να κάνετε με ένα τουρνουά

Δίπλα σε ένα τουρνουά του οποίου φροντίζετε μόνο τις κατατάξεις, η λίστα προσφέρει τους **Παίκτες** και τίποτα άλλο. Ανοίγει τη σελίδα του τουρνουά, όπου μπορείτε να αλλάξετε το όνομα παγκόσμιας κατάταξης οποιουδήποτε παίκτη του, να διαβάσετε τους υπευθύνους του και να τους γράψετε με το **Email στους υπευθύνους**, και να πάρετε τα παιχνίδια του για τις παγκόσμιες κατατάξεις από την καρτέλα **Κατατάξεις**, με τη **Λήψη παιχνιδιών για την παγκόσμια κατάταξη**. Δεν μπορείτε να αλλάξετε το τουρνουά, να το αρχειοθετήσετε ή να καταχωρίσετε αποτελέσματα σε αυτό, αφού αυτά είναι για τους υπευθύνους και τους καταχωρητές του. Ένα αρχειοθετημένο τουρνουά αυτού του είδους δεν έχει κουμπί· το όνομά του εξακολουθεί να ανοίγει τη σελίδα του.

Δίπλα σε ένα τουρνουά που διαχειρίζεστε ή στο οποίο καταχωρίζετε αποτελέσματα, η λίστα προσφέρει ό,τι προσφέρει σε κάθε υπεύθυνο ή καταχωρητή: τη **Διαχείριση** με το μολύβι (**Επεξεργασία**) και τον κάδο (**Αρχειοθέτηση**), ή τα **Αποτελέσματα**. Η ιδιότητα του υπευθύνου δεν αλλάζει τίποτα από αυτά.
