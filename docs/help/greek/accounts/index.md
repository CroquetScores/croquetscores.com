# Βοήθεια για τον λογαριασμό σας

Δεν χρειάζεστε λογαριασμό για να διαβάσετε ένα τουρνουά. Τον χρειάζεστε για να διοργανώσετε ένα τουρνουά και για να γράψετε στην ιστοσελίδα. Αυτοί οι οδηγοί λένε πώς να έχετε έναν, από την εγγραφή μέχρι τη λήθη του.

- [Εγγραφή και επιβεβαίωση της διεύθυνσης email σας](registering.md): τα δύο βήματα που φτιάχνουν έναν λογαριασμό και τι να κάνετε όταν δεν έρχεται το email.
- [Σύνδεση](signing-in.md): με κωδικό ή με Google και τι να κάνετε όταν δεν μπορείτε.
- [Κωδικοί](passwords.md): τι πρέπει να είναι ένας κωδικός, συμβουλές για την επιλογή του και πώς τον ελέγχει η ιστοσελίδα.
- [Φροντίδα του λογαριασμού σας](looking-after-your-account.md): το όνομά σας, η διεύθυνση email σας και η λήθη του λογαριασμού.

Κάθε οδηγός στέκεται μόνος του, οπότε μπορείτε να διαβάσετε αυτόν που χρειάζεστε.
