# Όροι χρήσης για υπευθύνους, καταχωρητές και σχολιαστές

Αυτοί είναι οι όροι υπό τους οποίους γράφετε σε αυτή την ιστοσελίδα: ως υπεύθυνος τουρνουά που καταχωρίζει ένα τουρνουά, ως καταχωρητής που καταχωρίζει αποτελέσματα ή ως σχολιαστής που γράφει έναν σχολιασμό ή ένα σχόλιο σε έναν. Σας ζητείται να τους αποδεχτείτε όταν εγγράφεστε και κάθε φορά που ξεκινάτε έναν σχολιασμό. Ισχύουν επιπλέον των [όρων χρήσης](/terms-of-use) που αποδέχεται κάθε αναγνώστης.

## Είστε υπεύθυνοι για ό,τι γράφετε

Ό,τι γράφετε δημοσιεύεται με το όνομά σας και είναι δικό σας. Οι απόψεις σε αυτό είναι δικές σας και όχι απαραίτητα των ανθρώπων που διαχειρίζονται την ιστοσελίδα.

## Αποτελέσματα

Καταχωρίζετε τα αποτελέσματα όπως παίχτηκαν και τα διορθώνετε όταν αποδεικνύονται λάθος. Οι παίκτες, οι σύλλογοί τους και οι παγκόσμιες κατατάξεις βασίζονται σε αυτά.

## Σχολιασμός

Ένας σχολιασμός είναι για να λέει στους αναγνώστες τι συμβαίνει στο τουρνουά. Δεν είναι χώρος για ευχές ή για συζήτηση.

## Τι δεν επιτρέπεται

Ό,τι και αν γράφετε, μη γράφετε τίποτα που:

- μπορεί να υποδαυλίσει τη βία ή το μίσος ή ταπεινώνει κάποιον λόγω φυλής, θρησκείας, εθνικότητας, φύλου, ηλικίας, αναπηρίας ή σεξουαλικού προσανατολισμού·
- επιτίθεται σε ένα πρόσωπο αντί για ό,τι έκανε: παίξτε την μπάλα, όχι τον παίκτη·
- παραβιάζει τον νόμο, όπως το να αντιγράφετε ό,τι δεν είναι δικό σας να αντιγράψετε ή να λέτε κάτι αναληθές που βλάπτει τη φήμη κάποιου·
- διαφημίζει, πουλά ή ζητιανεύει ή είναι ανεπιθύμητο (spam)·
- παραπέμπει σε ακατάλληλο υλικό ή παραπέμπει περισσότερο από όσο χρειάζεται·
- προσποιείται ότι είναι κάποιος άλλος ή δίνει τον αριθμό τηλεφώνου, την ταχυδρομική διεύθυνση ή τη διεύθυνση email οποιουδήποτε·
- βρίζει ή είναι γραμμένο με κεφαλαία.

## Τι μπορεί να κάνει η ιστοσελίδα

Όσοι διαχειρίζονται την ιστοσελίδα μπορούν να αλλάξουν ή να αφαιρέσουν οτιδήποτε γράφτηκε σε αυτή και παραβιάζει αυτούς τους όρους και μπορούν να κλείσουν έναν λογαριασμό που τους παραβιάζει συνεχώς.

## Αναφορά όσων γράφτηκαν

Αν δείτε στην ιστοσελίδα κάτι που παραβιάζει αυτούς τους όρους, αναφέρετέ το με email, στη διεύθυνση που βρίσκεται στο τέλος αυτής της σελίδας. Δώστε τη διεύθυνση ιστού του, παραθέστε ό,τι γράφτηκε και πείτε γιατί πρέπει να αφαιρεθεί. Κάθε αναφορά διαβάζεται, αλλά δεν αφαιρείται οτιδήποτε αναφέρεται.

## Αλλαγές

Αυτοί οι όροι μπορεί να αλλάξουν. Οι όροι σε αυτή τη σελίδα είναι αυτοί που ισχύουν και σας ζητείται να τους αποδεχτείτε ξανά όταν ξεκινήσετε έναν σχολιασμό την επόμενη φορά.
