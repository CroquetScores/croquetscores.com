# Τι νέο υπάρχει για τους υπευθύνους τουρνουά

## Κυκλοφόρησε στις 2026-10-27

Αυτές είναι οι σημαντικότερες αλλαγές για όσους διοργανώνουν τουρνουά. Η [βοήθεια για υπευθύνους τουρνουά](../tournament-managers/index.md) έχει όλες τις λεπτομέρειες.

- **Οι παίκτες καταχωρίζονται μία φορά, στο τουρνουά.** Στην παλιά ιστοσελίδα, οι παίκτες προστίθεντο μέσα σε κάθε αγώνισμα. Τώρα η καρτέλα **Παίκτες** του τουρνουά είναι εκεί όπου τους προσθέτετε, τους διορθώνετε, τους βάζετε σε σειρά και τους αρχειοθετείτε, και ένας παίκτης που διορθώνεται εκεί διορθώνεται σε κάθε αγώνισμα όπου συμμετέχει και σε κάθε δημόσια σελίδα. Δείτε [Παίκτες](../tournament-managers/standard-tournament/players.md).

- **Οι παίκτες μπαίνουν σε ένα αγώνισμα από μια λίστα.** Στη σελίδα ενός αγωνίσματος, επιλέξτε έναν παίκτη του τουρνουά από την αναπτυσσόμενη λίστα και πατήστε **Προσθήκη παίκτη**. Η αναπτυσσόμενη λίστα προσφέρει μόνο παίκτες που δεν συμμετέχουν ήδη στο αγώνισμα. Σε ένα νοκ-άουτ προσφέρει επίσης **Bye** για τις θέσεις που περισσεύουν. Δείτε [Καταχώριση παικτών σε ένα αγώνισμα](../tournament-managers/standard-tournament/entering-players-in-a-competition.md).

- **Ένα κουμπί προσθέτει ένα αγώνισμα.** Στη θέση των χωριστών κουμπιών για νέο μπλοκ, νέο ελβετικό και νέο νοκ-άουτ, πατήστε **Προσθήκη αγωνίσματος**. Το παράθυρο ζητά το όνομα και το είδος (ένα μπλοκ, ένα νοκ-άουτ ή ένα ελβετικό) και μετά ό,τι χρειάζεται αυτό το είδος: ποιος είναι ο καλύτερος από για κάθε αγώνα και, για ένα νοκ-άουτ, οι θέσεις της κλήρωσής του. Μένει ανοιχτό ώστε να προσθέσετε πολλά ταυτόχρονα. Το είδος ενός αγωνίσματος δεν μπορεί να αλλάξει αργότερα: αρχειοθετήστε το και προσθέστε το ξανά. Δείτε [Αγωνίσματα](../tournament-managers/standard-tournament/competitions.md).

- **Σημειώσεις υπευθύνων: χρησιμοποιήστε τες αντί για σχολιασμό για να πείτε στους παίκτες ό,τι πρέπει να γνωρίζουν.** Τη μορφή, μια αλλαγή στη σειρά των παιχνιδιών, την ώρα του γεύματος. Μια σημείωση γράφεται στην καρτέλα **Σημειώσεις** του τουρνουά, με έναν τίτλο και μια περιγραφή σε Markdown, και μπορείτε να τη δείτε σε προεπισκόπηση πριν την προσθέσετε. Οι παίκτες βρίσκουν τις σημειώσεις στη δημόσια σελίδα Σημειώσεις του τουρνουά. Μια σημείωση που δεν έχουν διαβάσει σημαδεύεται με αστερίσκο, όπως και η ενότητα Σημειώσεις σε κάθε σελίδα του τουρνουά, μέχρι να την ανοίξουν. Μια σημείωση που επεξεργάζεστε σημαδεύεται ξανά για όλους όσους την είχαν διαβάσει. Δείτε [Σημειώσεις](../tournament-managers/standard-tournament/notes.md).

- **Οι Σημειώσεις του τουρνουά στην παλιά ιστοσελίδα είναι τώρα ο Υπότιτλος.** Ό,τι γράψατε εκεί κρατιέται ως ο υπότιτλος του τουρνουά και εξακολουθεί να εμφανίζεται κάτω από το όνομα του τουρνουά σε κάθε δημόσια σελίδα. Γράφεται σε Markdown και μπορεί να έχει έως 2000 χαρακτήρες. Είναι για ό,τι πρέπει να γνωρίζουν οι αναγνώστες σε όποια σελίδα και αν βρίσκονται. Χρησιμοποιήστε μια σημείωση για νέα που αλλάζουν καθώς προχωρά το τουρνουά.
