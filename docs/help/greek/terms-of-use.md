# Όροι χρήσης

Αυτοί είναι οι όροι υπό τους οποίους διαβάζετε αυτή την ιστοσελίδα. Είναι σύντομοι, επειδή η ανάγνωση ζητά λίγα από εσάς.

## Τι είναι η ιστοσελίδα

Η ιστοσελίδα δείχνει τουρνουά κροκέ: τους παίκτες τους, τα παιχνίδια τους και τα αποτελέσματά τους, και τους σχολιασμούς που γράφονται για αυτά καθώς παίζονται. Τη διαχειρίζονται εθελοντές και πληρώνεται με δωρεές.

## Σε τι μπορείτε να βασιστείτε

Τα αποτελέσματα καταχωρίζονται από όσους διοργανώνουν κάθε τουρνουά και από τους καταχωρητές που εμπιστεύονται, συνήθως καθώς παίζονται τα παιχνίδια. Ένα αποτέλεσμα μπορεί να είναι λάθος, να καθυστερήσει ή να διορθωθεί αργότερα. Τον τελευταίο λόγο για ένα αποτέλεσμα τον έχουν οι ίδιοι οι αξιωματούχοι του τουρνουά και όχι αυτή η ιστοσελίδα.

Οι σχολιασμοί και τα σχόλια ανήκουν στους συντάκτες τους. Οι απόψεις που περιέχουν δεν είναι απαραίτητα των ανθρώπων που διαχειρίζονται την ιστοσελίδα.

## Χρήση όσων διαβάζετε

Είστε ευπρόσδεκτοι να διαβάζετε όσα δείχνει η ιστοσελίδα, να τη συνδέετε και να τη μοιράζεστε. Μην αντιγράφετε ολόκληρη την ιστοσελίδα και μην της ζητάτε σελίδες πιο γρήγορα από όσο θα διάβαζε ένας άνθρωπος: λειτουργεί με δωρεές και αυτό το κόστος είναι όλων.

## Γράψιμο στην ιστοσελίδα

Αν διαχειρίζεστε ένα τουρνουά, καταχωρίζετε αποτελέσματα ή γράφετε σχολιασμό, αποδέχεστε επίσης τους [όρους χρήσης για υπευθύνους, καταχωρητές και σχολιαστές](/admin/terms-of-use).

## Αλλαγές

Αυτοί οι όροι μπορεί να αλλάξουν. Οι όροι σε αυτή τη σελίδα είναι αυτοί που ισχύουν.
