# Τα σημεία πρόσβασης του API

Κάθε διεύθυνση βρίσκεται κάτω από το `/api/v1` του ιστότοπου, και κάθε απάντηση είναι JSON. Όσα ισχύουν για όλες, όπως τα κλειδιά, τα όρια, τα σφάλματα και οι φτηνές ερωτήσεις, βρίσκονται στη [βοήθεια για προγραμματιστές εφαρμογών](index.md).

Υπάρχουν δύο είδη, και μία σελίδα για το καθένα:

- Τα [σημεία πρόσβασης GET](get-endpoints.md) διαβάζουν: τα τουρνουά ενός έτους, ένα τουρνουά, ένα αγώνισμα, την κατάταξη και τα παιχνίδια του, τα αθλήματα, τις μορφές και τις χώρες που μπορεί να είναι ένα τουρνουά, τους παίκτες της παγκόσμιας κατάταξης και τα παιχνίδια τους, τι επιτρέπεται σε ένα κλειδί και τι άλλαξε ή αρχειοθετήθηκε.
- Τα [σημεία πρόσβασης POST](post-endpoints.md) αλλάζουν κάτι: η δημιουργία ενός τουρνουά, των αγωνισμάτων, των παικτών, των ομάδων και των παιχνιδιών του, και το ποιος μπορεί να το διαχειρίζεται και να καταχωρεί σκορ.
