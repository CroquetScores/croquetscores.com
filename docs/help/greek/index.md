# Βοήθεια

Πώς να χρησιμοποιήσετε την ιστοσελίδα, για όσους τη χρησιμοποιούν.

- [Αναγνώστες](readers/index.md): πώς διαβάζετε ένα τουρνουά σε έναν περιηγητή, από την επιλογή του θέματος και της γλώσσας μέχρι το τι χρειάζεται η ιστοσελίδα από τον περιηγητή σας.
- [Ο λογαριασμός σας](accounts/index.md): εγγραφή, σύνδεση, κωδικοί και φροντίδα του λογαριασμού.
- [Υπεύθυνοι τουρνουά](tournament-managers/index.md): πώς διοργανώνετε ένα τουρνουά από τη διαχείριση, από τη δημιουργία του μέχρι τις σελίδες που παρακολουθούν οι παίκτες του.
- [Υπεύθυνοι παγκόσμιας κατάταξης](world-ranking-officers/index.md): τι σας δίνουν η λίστα τουρνουά της διαχείρισης και η καρτέλα Κατατάξεις ενός τουρνουά, πέρα από τα τουρνουά που διοργανώνετε.
