# Βοήθεια για αναγνώστες

Δεν χρειάζεστε λογαριασμό για να διαβάσετε τα αποτελέσματα ενός τουρνουά και αυτοί οι οδηγοί είναι για όποιον το κάνει αυτό, σε έναν περιηγητή σε τηλέφωνο, tablet ή υπολογιστή. Λένε πώς να έχετε την ιστοσελίδα όπως σας αρέσει να τη διαβάζετε και τι χρειάζεται από τον περιηγητή σας.

- [Εύρεση και παρακολούθηση ενός τουρνουά](following-a-tournament.md): εύρεση, περιορισμός και ταξινόμηση λιστών, ανάγνωση ενός αγωνίσματος, σημειώσεις και τι νέο υπάρχει.
- [Επιλογή του θέματος και της γλώσσας](theme-and-language.md): φωτεινό ή σκούρο και η γλώσσα στην οποία σας μιλά η ιστοσελίδα.
- [Σενάρια και cookies](scripting-and-cookies.md): τι κρατά η ιστοσελίδα στον περιηγητή σας και το ένα πράγμα που χρειάζεται ενεργοποιημένα σενάρια.
