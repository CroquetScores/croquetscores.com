# Anmelden

Wählen Sie **Anmelden** im Menü **Konto**. Sie haben zwei Wege hinein.

## Mit Ihrem Passwort

Geben Sie Ihre **E-Mail-Adresse** und Ihr **Passwort** an und drücken Sie **Anmelden**. Sie kommen zurück zu der Seite, die Sie zum Anmelden geschickt hat, oder in die Verwaltung, wenn es keine war.

Ist eines von beiden falsch, sagt die Seite nur, dass E-Mail-Adresse oder Passwort nicht stimmen. Sie sagt nicht, welches, und auch nicht, ob die Adresse ein Konto hat, damit niemand so herausfinden kann, wer eines hat.

Eine Adresse, bei der die Anmeldung innerhalb einer Stunde zehnmal fehlgeschlagen ist, wird für den Rest dieser Stunde gesperrt. Wer sich für sie anmeldet, bekommt gesagt, er solle eine Stunde warten und es dann noch einmal versuchen, auch mit dem richtigen Passwort. Es ist eine Grenze für das Raten, und eine Grenze, die das richtige Passwort durchließe, würde niemanden am Raten hindern.

Ein Konto, dessen E-Mail-Adresse nicht bestätigt wurde, hat noch kein Passwort, deshalb kann man sich dort nicht anmelden. Folgen Sie dem Link in der E-Mail oder fordern Sie einen neuen an: [Registrieren und bestätigen](registering.md) sagt, wie.

## Mit Google oder Facebook

**Mit Google anmelden**, **Mit Facebook anmelden**, **Mit Google registrieren** und **Mit Facebook registrieren** benutzen das Google- oder Facebook-Konto, das Sie wählen, sodass die Website nie ein Passwort dafür sieht. Ein so angelegtes Konto hat kein Passwort, bis Sie eines verlangen.

Facebook gibt der Website Ihre E-Mail-Adresse nur, wenn Sie bei Facebook eine bestätigte haben und sie weitergeben lassen. Ohne sie kann die Website Ihr Konto weder finden noch anlegen und sagt Ihnen das: Nutzen Sie stattdessen Ihre E-Mail-Adresse.

Um sich auch mit einem Passwort anmelden zu können, wählen Sie **Passwort festlegen** im Menü **Konto** und drücken Sie **Link per E-Mail senden**. Der Link geht an die E-Mail-Adresse Ihres Kontos und legt ein Passwort fest, so wie der Link für ein vergessenes Passwort.

## Wenn Sie Ihr Passwort vergessen haben

Drücken Sie auf der Anmeldeseite **Passwort vergessen?**, geben Sie Ihre E-Mail-Adresse an und drücken Sie **Weg zurück ins Konto senden**. Die Seite fordert Sie auf, in Ihrem Postfach nachzusehen, egal ob die Adresse ein Konto hat. Was geschickt wird, hängt von der Adresse ab, und nur ihr Besitzer liest es: ein Link zum Festlegen eines neuen Passworts, der Link zum Bestätigen einer Adresse, die nie bestätigt wurde, oder ein Link zum Registrieren.

Der Link zum Festlegen eines neuen Passworts funktioniert einmal und eine Stunde lang. Öffnen Sie ihn, tippen Sie das neue Passwort zweimal ein und drücken Sie **Mein neues Passwort festlegen**. Mit einem neuen Passwort wird das Konto überall abgemeldet, auf jedem Gerät, denn vielleicht legen Sie es fest, weil jemand anderes hineingekommen ist. Melden Sie sich danach mit dem Passwort an, das Sie gewählt haben.

Die Anforderung eines Wegs zurück ins Konto ist begrenzt, damit die Seite nicht dazu benutzt werden kann, jemandes Postfach zu füllen.

## Abmelden

Wählen Sie **Abmelden** im Menü **Konto**.
