# Die Endpunkte der API

Jede Adresse liegt unter `/api/v0` der Website, und jede Antwort ist JSON. Was für alle gilt, wie Schlüssel, Kontingente, Fehler und sparsames Abfragen, steht in der [Hilfe für App-Entwickler](index.md).

Es gibt zwei Arten, und für jede eine Seite:

- [Die GET-Endpunkte](get-endpoints.md) lesen: die Turniere eines Jahres, ein Turnier, einen Wettbewerb, seine Tabelle und Spiele, was ein Schlüssel darf und was sich geändert hat oder archiviert wurde.
- [Die POST-Endpunkte](post-endpoints.md) ändern etwas: ein Turnier, seine Wettbewerbe, Spieler, Teams und Spiele anlegen und festlegen, wer es leiten und Ergebnisse erfassen darf.
