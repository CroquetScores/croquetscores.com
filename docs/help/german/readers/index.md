# Hilfe für Leser

Sie brauchen kein Konto, um die Ergebnisse eines Turniers zu lesen. Diese Anleitungen sind für alle, die das tun, in einem Browser auf dem Handy, dem Tablet oder dem Computer. Sie sagen, wie Sie die Website so einstellen, wie Sie sie gern lesen, und was sie von Ihrem Browser braucht.

- [Darstellung und Sprache wählen](theme-and-language.md): hell oder dunkel, und die Sprache, in der die Website zu Ihnen spricht.
- [Skripte und Cookies](scripting-and-cookies.md): was die Website in Ihrem Browser speichert, und das Eine, wofür Skripte eingeschaltet sein müssen.
