# Hilfe für Leser

Du brauchst kein Konto, um die Ergebnisse eines Turniers zu lesen. Diese Anleitungen sind für alle, die das tun, in einem Browser auf dem Handy, dem Tablet oder dem Computer. Sie sagen, wie du die Website so einstellst, wie du sie gern liest, und was sie von deinem Browser braucht.

- [Darstellung und Sprache wählen](theme-and-language.md): hell oder dunkel, und die Sprache, in der die Website zu dir spricht.
- [Skripte und Cookies](scripting-and-cookies.md): was die Website in deinem Browser speichert, und das Eine, wofür Skripte eingeschaltet sein müssen.
