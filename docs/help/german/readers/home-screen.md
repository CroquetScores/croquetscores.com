# Die Website zum Home-Bildschirm hinzufügen

Sie können die Website auf dem Home-Bildschirm Ihres Handys ablegen, mit einem eigenen Symbol, und sie von dort in einem eigenen Fenster ohne die Adressleiste des Browsers öffnen, so wie Sie eine App öffnen. Es ist dieselbe Website, von denselben Seiten gezeichnet, sie braucht also eine Verbindung, genau wie in einem Browser.

Das Symbol gehört der Website: Croquet Scores und Gateball Scores haben je eines, sodass Sie sie auseinanderhalten können. Die Testwebsite lässt sich nicht auf den Home-Bildschirm legen. Sie ist ein sicherer Ort, um die Website kennenzulernen, und was dort eingegeben wird, kann jederzeit entfernt werden.

## Auf einem iPhone {#on-an-iphone}

Ein iPhone lässt der Website keine Schaltfläche dafür zu, deshalb geht es über den Browser, in vier Schritten.

1. Öffnen Sie die Website in Safari.
2. Tippen Sie auf **Teilen**, das Quadrat mit dem Pfeil nach oben, unten auf dem Bildschirm.
3. Scrollen Sie in der Liste, die sich öffnet, nach unten und tippen Sie auf **Zum Home-Bildschirm**.
4. Ändern Sie bei Bedarf den Namen und tippen Sie dann auf **Hinzufügen**.

Auch andere Browser auf dem iPhone, etwa Chrome, können das ab iOS 16.4, wenn sie es anbieten. Suchen Sie im Browser dieselbe Schaltfläche **Teilen** und gehen Sie genauso vor. Vor iOS 16.4 kann es nur Safari.

## Auf einem iPad {#on-an-ipad}

Die Schritte sind dieselben, aber die Schaltfläche **Teilen** ist oben auf dem Bildschirm, neben der Adressleiste, und nicht unten.

## Auf anderen Handys {#on-other-phones}

Wenn Ihr Browser meldet, dass sich die Website installieren lässt, zeigt die Website am Ende jeder Seite eine Schaltfläche **Website installieren**. Tippen Sie darauf und beantworten Sie die Frage des Browsers. Gibt es keine solche Schaltfläche, öffnen Sie das Menü des Browsers, in Chrome die drei Punkte, und suchen Sie nach **App installieren** oder **Zum Startbildschirm hinzufügen**.

## Wenn es keine Option gibt {#if-there-is-no-option}

Ein Browser bietet das nicht an, wenn Sie in einem privaten Fenster lesen. Öffnen Sie die Website in einem normalen Fenster und versuchen Sie es noch einmal. Ein veralteter Browser bietet es womöglich gar nicht an; dann hilft nur, ihn zu aktualisieren.
