# Richtlinie zur Löschung von Daten

Wie Sie löschen lassen, was diese Website über Sie speichert. Sie gilt, wie auch immer Sie sich anmelden: mit Facebook, mit Google oder mit einer E-Mail-Adresse und einem Passwort.

## So lassen Sie Ihre Daten löschen

1. Melden Sie sich bei dem Konto an, das gelöscht werden soll, so wie Sie es immer tun.
2. Öffnen Sie [Konto vergessen](/account/forget-account); die Seite finden Sie auch im Kontomenü und in Ihrem Profil.
3. Drücken Sie **Link per E-Mail senden**. Damit sicher ist, dass Sie es sind, schickt die Website einen Link an die eigene Adresse des Kontos. Gelöscht wird nichts, bevor Sie ihm gefolgt sind.
4. Folgen Sie dem Link in der E-Mail. Er funktioniert einmal, 15 Minuten lang, und nur solange Sie bei dem Konto angemeldet sind. Er zeigt, was Vergessen bedeutet.
5. Drücken Sie **Mein Konto vergessen**.

Sie werden überall abgemeldet, wo Sie angemeldet waren, und beim Konto kann sich nie wieder jemand anmelden.

## Was gelöscht wird

Ihr Name und Ihre E-Mail-Adresse werden überall, wo die Website sie speichert, für immer durch „Forgotten Account“ und eine Nummer ersetzt und durch eine Adresse bei example.com, die niemandem gehört. Niemand kann sie je wieder lesen, auch nicht die Menschen, die die Website betreiben. Dasselbe geschieht mit dem Google- oder Facebook-Konto, das mit Ihrem verknüpft ist, damit nichts das Konto mit Ihnen verbindet. Ihre E-Mail-Adresse kann danach wieder als neues Konto registriert werden.

## Was bleibt

Die Kennung Ihres Kontos bleibt erhalten. Es ist eine Zufallszahl, die für das Konto erzeugt wurde und nichts darüber sagt, wer Sie sind. Was Sie veröffentlicht haben, bleibt mit ihr verbunden, unter dem Namen „Forgotten Account“ und dieser Nummer: die Turniere, die Sie angelegt haben, die Ergebnisse, die Sie eingetragen haben, und die Kommentare, die Sie geschrieben haben. Es ist die Aufzeichnung der Spiele, und die Menschen, die dabei gespielt haben, haben einen Anspruch darauf. Sie sagt nicht mehr, wer Sie waren.

Eine Kopie der Website, die gemacht wurde, bevor Sie vergessen wurden, etwa eine Sicherung, hat noch, was sie damals hatte, solange die Kopie aufbewahrt wird.

## Gut zu wissen

- **Wenn Sie die App in Ihren Facebook-Einstellungen entfernen, wird hier nichts gelöscht.** Facebook gibt dann nur nichts mehr an die Website weiter. Um Ihre Daten löschen zu lassen, folgen Sie den Schritten oben.
- **Es lässt sich nicht rückgängig machen.** Deshalb wird zweimal danach gefragt.
- **Der einzige Administrator kann nicht vergessen werden.** Wenn Sie der einzige Administrator dieser Website sind, geben Sie die Rolle Administrator zuerst an jemand anderen.
- **Wenn Sie sich nicht anmelden können,** legen Sie auf der Seite [Passwort vergessen](/account/forgot-password) ein neues Passwort fest, melden Sie sich dann an und folgen Sie den Schritten oben. Wenn Sie sich mit Facebook oder Google angemeldet haben, melden Sie sich auf diesem Weg an.

Was die Website speichert und warum, steht in der [Datenschutzerklärung](/privacy).

## Fragen

Alles, was hier nicht steht, oder jeder Zweifel daran, ob Ihre Daten gelöscht wurden, ist Sache der Menschen, die die Website betreiben.
