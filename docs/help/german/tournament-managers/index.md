# Hilfe für die Turnierleitung

Ein Turnier auf dieser Website wird in der Verwaltung von seiner Turnierleitung geführt: von der Person, die es angelegt hat, und von allen, die sie seither zu Turnierleitern gemacht hat. Diese Anleitungen sagen, wie das geht, vom Anmelden bis zu einem Turnier, dessen Ergebnisse öffentlich zu sehen sind.

Es gibt zwei Arten von Turnieren und für jede eine Anleitung. Jede Anleitung steht für sich, du kannst also die für das Turnier lesen, das du leitest, und sonst nichts.

- [Ein Standardturnier leiten](standard-tournament/index.md): ein Turnier zwischen einzeln gemeldeten Spielern, in Gruppen, K.-o.-Runden und Schweizer Systemen. Ein Vereinswochenende, ein offenes Turnier, eine Meisterschaft.
- [Ein Mannschaftsturnier leiten](teams-tournament/index.md): ein Turnier zwischen Mannschaften, gespielt als Tests zwischen zwei Seiten, die aus Begegnungen zwischen ihren Spielern bestehen. Eine Testserie, ein Interstate Shield, eine Mannschaftsweltmeisterschaft.

Welcher Art ein Turnier ist, entscheidet sein **Format** beim Anlegen: Standard für die erste und Mannschaften, Eire Cup, Interstate Shield oder GC World Team Championship für die zweite.
