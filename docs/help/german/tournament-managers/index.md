# Hilfe für die Verantwortlichen

Ein Turnier auf dieser Website wird in der Verwaltung von seinen Verantwortlichen geführt: von der Person, die es angelegt hat, und von allen, die sie seither zu Verantwortlichen gemacht hat. Diese Anleitungen sagen, wie das geht, vom Anmelden bis zu einem Turnier, dessen Ergebnisse öffentlich zu sehen sind.

Es gibt zwei Arten von Turnieren und für jede eine Anleitung. Jede Anleitung steht für sich, Sie können also die für das Turnier lesen, das Sie leiten, und sonst nichts.

- [Ein Standardturnier leiten](standard-tournament/index.md): ein Turnier zwischen einzeln gemeldeten Spielern, in Gruppen, K.-o.-Runden und Schweizer Systemen. Ein Vereinswochenende, ein offenes Turnier, eine Meisterschaft.
- [Ein Mannschaftsturnier leiten](teams-tournament/index.md): ein Turnier zwischen Mannschaften, gespielt als Tests zwischen zwei Seiten, die aus Begegnungen zwischen ihren Spielern bestehen. Eine Testserie, ein Interstate Shield, eine Mannschaftsweltmeisterschaft.

Welcher Art ein Turnier ist, entscheidet sein **Format** beim Anlegen: Standard für die erste und Mannschaften, Eire Cup, Interstate Shield oder GC-Mannschaftsweltmeisterschaft für die zweite.
