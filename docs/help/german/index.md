# Hilfe

Wie die Website benutzt wird, für die Menschen, die sie benutzen.

- [Verantwortliche](tournament-managers/index.md): ein Turnier in der Verwaltung führen, vom Anlegen bis zu den Seiten, die seine Spieler verfolgen.
- [Leser](readers/index.md): ein Turnier im Browser lesen, von der Wahl der Darstellung und der Sprache bis zu dem, was die Website von Ihrem Browser braucht.
- [Ihr Konto](accounts/index.md): sich registrieren, anmelden, Passwörter und die Pflege eines Kontos.
- [Weltranglistenbeauftragte](world-ranking-officers/index.md): was die Turnierliste in der Verwaltung Ihnen über die Turniere hinaus gibt, die Sie leiten.
