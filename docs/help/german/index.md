# Hilfe

Wie die Website benutzt wird, für die Menschen, die sie benutzen.

- [Turnierleitung](tournament-managers/index.md): ein Turnier in der Verwaltung führen, vom Anlegen bis zu den Seiten, die seine Spieler verfolgen.
- [Leser](readers/index.md): ein Turnier im Browser lesen, von der Wahl der Darstellung und der Sprache bis zu dem, was die Website von deinem Browser braucht.
