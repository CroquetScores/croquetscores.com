# Aide

Comment utiliser le site, pour ceux qui l’utilisent.

- [Gestionnaires de tournoi](tournament-managers/index.md) : organiser un tournoi depuis l’administration, de sa création jusqu’aux pages que ses joueurs suivent.
- [Lecteurs](readers/index.md) : lire un tournoi dans un navigateur, du choix du thème et de la langue à ce que le site demande de votre navigateur.
