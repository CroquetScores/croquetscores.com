# Aide pour votre compte

Vous n’avez pas besoin d’un compte pour lire un tournoi. Il en faut un pour organiser un tournoi et pour écrire sur le site. Ces guides disent comment en avoir un, de l’inscription jusqu’à l’oubli du compte.

- [S’inscrire et confirmer votre adresse e-mail](registering.md) : les deux étapes qui font un compte, et que faire quand l’e-mail n’arrive pas.
- [Se connecter](signing-in.md) : avec un mot de passe, avec Google ou avec Facebook, et que faire quand vous n’y arrivez pas.
- [Mots de passe](passwords.md) : ce qu’un mot de passe doit être, des conseils pour en choisir un, et comment le site le vérifie.
- [Prendre soin de votre compte](looking-after-your-account.md) : votre nom, votre adresse e-mail, et faire oublier le compte.

Chaque guide se suffit à lui-même : lisez celui dont vous avez besoin.
