# Aide pour les lecteurs

Vous n’avez pas besoin de compte pour lire les résultats d’un tournoi. Ces guides s’adressent à toute personne qui les consulte, dans un navigateur, sur un téléphone, une tablette ou un ordinateur. Ils expliquent comment avoir le site tel que vous aimez le lire, et ce qu’il demande à votre navigateur.

- [Choisir le thème et la langue](theme-and-language.md) : clair ou sombre, et la langue dans laquelle le site vous parle.
- [Scripts et cookies](scripting-and-cookies.md) : ce que le site conserve dans votre navigateur, et la seule chose qui demande que les scripts soient activés.
