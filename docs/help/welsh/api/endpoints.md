# Terfynbwyntiau'r API

Mae pob cyfeiriad o dan `/api/v0` ar y wefan, ac mae pob ateb yn JSON. Mae'r hyn sy'n wir am bob un, fel allweddi, lwfansau, gwallau a gofyn yn rhad, yn y [cymorth i ddatblygwyr apiau](index.md).

Mae dau fath, a thudalen i bob un:

- Mae'r [terfynbwyntiau GET](get-endpoints.md) yn darllen: twrnameintiau blwyddyn, twrnamaint, cystadleuaeth, ei safleoedd a'i gemau, y campau, y fformatau a'r gwledydd y gall twrnamaint fod, chwaraewyr safleoedd y byd a'u gemau, beth y caiff allwedd ei wneud, a beth sydd wedi newid neu wedi'i archifo.
- Mae'r [terfynbwyntiau POST](post-endpoints.md) yn newid rhywbeth: gwneud twrnamaint, ei gystadlaethau, ei chwaraewyr, ei dimau a'i gemau, a phwy a gaiff ei reoli a chadw'r sgorau.
