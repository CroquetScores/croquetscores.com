# 管理者、记分员和评论员使用条款

这些是您在本站上写作所依据的条款：作为录入赛事的赛事管理者，作为录入结果的记分员，或作为撰写评论或对评论发表留言的评论员。您注册时以及每次发起评论时，都会被要求同意这些条款。它们是在每位读者所同意的[使用条款](/terms-of-use)之上增加的。

## 您对自己所写的内容负责

您所写的内容以您的名义发布，并且属于您。其中的观点是您的，不一定是运营本站的人的观点。

## 结果

按比赛实际情况录入结果，发现有误时予以更正。选手、他们的俱乐部和世界排名都依赖这些结果。

## 评论

评论用于告诉读者赛事上正在发生什么。它不是用来送上祝福或闲聊的地方。

## 不允许什么

无论您写什么，都不要写出以下内容：

- 可能煽动暴力或仇恨，或因种族、宗教、民族、性别、年龄、残疾或性取向而羞辱任何人；
- 攻击一个人而不是他所做的事：打球，不要打人；
- 违反法律，例如复制不属于您可以复制的东西，或说不真实的话而损害某人的名誉；
- 做广告、销售或招揽，或属于垃圾信息；
- 链接到不适当的材料，或链接超出所需；
- 冒充他人，或提供任何人的电话号码、邮寄地址或电子邮件地址；
- 说脏话，或全部用大写字母书写。

## 本站可以做什么

运营本站的人可以更改或删除本站上任何违反这些条款的内容，并可以关闭一个不断违反这些条款的账户。

## 举报所写内容

如果您在本站上看到违反这些条款的内容，请通过电子邮件举报，发送到本页页脚的地址。请给出它的网址，引用所写的内容，并说明为什么应该删除。每一份举报都会被阅读，但并非所有被举报的内容都会被删除。

## 变更

这些条款可能会变更。以本页上的条款为准，您下次发起评论时会被要求再次同意。
