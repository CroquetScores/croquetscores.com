# 锦标赛管理员的新功能

## 发布于 2026-10-19

以下是对举办锦标赛的人影响最大的变化。[锦标赛管理员帮助](../tournament-managers/index.md)里有全部细节。

- **选手只需录入一次，录入到锦标赛中。** 在旧网站上，选手是在每个赛事里添加的。现在，锦标赛的**选手**标签页是添加、更正、排序和归档选手的地方，在这里更正的选手，会在他参加的每个赛事和每个公开页面上同时更正。参见[选手](../tournament-managers/standard-tournament/players.md)。
- **从列表中把选手放进赛事。** 在赛事页面，从下拉列表中选择锦标赛的一名选手，然后按**添加选手**。下拉列表只提供尚未在该赛事中的选手。在淘汰赛中，剩下的位置还可以选择**轮空**。参见[把选手录入赛事](../tournament-managers/standard-tournament/entering-players-in-a-competition.md)。
- **一个按钮添加赛事。** 以前有单独的新建小组赛、新建瑞士制和新建淘汰赛按钮，现在只需按**添加赛事**。对话框会询问名称和类型（小组赛、淘汰赛或瑞士制），然后询问该类型所需的内容：每场比赛是几局决胜，淘汰赛还要问签表有多少个位置。对话框会保持打开，方便你一次添加多个。赛事的类型之后不能更改：请归档它，再重新添加。参见[赛事](../tournament-managers/standard-tournament/competitions.md)。
- **管理员备注：想告诉选手需要知道的事，请用它来代替评论。** 比如赛制、比赛顺序的变动、午餐的时间。备注写在锦标赛的**备注**标签页上，包含标题和用 Markdown 写的说明，添加之前可以预览。选手在锦标赛公开的“备注”页面上查看备注。他们没读过的备注，以及锦标赛每个页面上的“备注”栏目，都会带星号，直到他们打开为止。你修改过的备注，会对所有读过它的人重新标记。参见[备注](../tournament-managers/standard-tournament/notes.md)。
- **旧网站锦标赛的“备注”现在是副标题。** 你在那里写的内容会保留为锦标赛的副标题，并仍显示在每个公开页面上锦标赛名称的下方。它用 Markdown 书写，最多 2000 个字符，用来放读者无论在哪个页面都应该知道的内容。随着比赛进行而变化的消息，请用备注。
