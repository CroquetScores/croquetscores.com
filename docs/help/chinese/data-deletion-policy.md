# 数据删除政策

如何让本站保存的关于您的信息被删除。无论您以何种方式登录，都适用：Facebook、Google，或电子邮件地址加密码。

## 如何让它被删除

1. 像平时一样，登录您想要删除的账户。
2. 打开[抹除账户](/account/forget-account)，它也在账户菜单和您的个人资料中。
3. 点击**给我发送链接**。为确认是您本人，本站会向您账户自己的地址发送一个链接。在您点击该链接之前，不会删除任何内容。
4. 点击邮件中的链接。它只能使用一次，有效期 15 分钟，并且只在您已登录该账户时有效。页面会说明抹除意味着什么。
5. 点击**抹除我的账户**。

您会在所有已登录的地方退出登录，此后再也无法登录该账户。

## 删除的内容

您的姓名和电子邮件地址，在本站保存它们的所有地方，都会被永久替换为“Forgotten Account”和一个编号，以及一个属于 example.com、不属于任何人的地址。任何人都无法再读取它们，运营本站的人也不例外。与您的账户关联的 Google 或 Facebook 账户也会同样处理，使任何信息都无法再把该账户与您联系起来。之后，您的电子邮件地址可以重新注册，成为一个新账户。

## 保留的内容

您账户的标识符会保留。它是为该账户随机生成的一个编号，不透露任何关于您是谁的信息。您发布的内容会与它一起保留，名称为“Forgotten Account”和该编号：您创建的赛事、您录入的成绩，以及您写的评论。这是比赛的记录，参与比赛的人对它享有权利。它不再说明您是谁。

在您被抹除之前制作的本站副本，例如备份，只要该副本仍被保留，其中仍有当时的内容。

## 须知

- **在 Facebook 设置中移除该应用，并不会删除这里的任何内容。** 它只是阻止 Facebook 向本站共享更多信息。要让您的数据被删除，请按上面的步骤操作。
- **无法撤销。** 所以会询问两次。
- **唯一的管理员无法被抹除。** 如果您是本站唯一的管理员，请先把管理员角色授予其他人。
- **如果您无法登录，** 请使用[忘记密码](/account/forgot-password)页面设置新密码，然后登录并按上面的步骤操作。如果您是用 Facebook 或 Google 登录的，请用同样的方式登录。

本站保存什么以及为什么保存，请见[隐私声明](/privacy)。

## 提问

这里没有说明的任何事，或对您的数据是否已被删除的任何疑问，都可以向运营本站的人询问。
