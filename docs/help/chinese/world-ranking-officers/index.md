# 世界排名负责人帮助

世界排名负责人负责一个或多个运动项目的世界排名。管理后台里任何已登录的读者能用的一切，您都能用：您可以创建赛事，也可以管理或记分您被指定为管理员或记分员的赛事，就像[赛事管理者](../tournament-managers/index.md)那样。本页只讲您另外获得的功能，它们在 `/admin` 的赛事列表上，以及在其他年份的同一列表上，如 `/admin/2025`、`/admin/2024` 等。

## 您所负责运动项目的每一个赛事

您的列表包含您所负责运动项目的每一个赛事，不论由谁举办，也包含您管理或记分的赛事。这比您想逐条阅读的要多，所以列表可以缩小范围，方法见下文。

提供给您的年份，是这些赛事开始的年份，以及您自己赛事的年份。选择顶部的某个标签，或选择**更早的年份**查看其余年份，列表就是该年的。`/admin` 是今年。

## 缩小列表范围

**新建赛事**旁边，在**显示**标签下有三个按钮：

- **管理员/记分员**列出您管理或记分的赛事。
- **世界排名**列出含有计入世界排名的竞赛的赛事。
- **非世界排名**列出没有这种竞赛的赛事。

处于开启状态的按钮带有勾号。只要有一个适用于某赛事的按钮开启，该赛事就会列出，所以每个按钮都是往列表里添加赛事，而没有一个会去掉赛事。**管理员/记分员**和**世界排名**默认开启，**非世界排名**默认关闭，所以一开始您看到的是您自己运作的赛事和排名所依据的赛事，按下**非世界排名**即可查看其余的。

如果您把所有按钮都关闭，列表为空，并提示没有符合条件的赛事，按钮仍然保留，您可以重新开启其中一个。

这些按钮写在页面的地址里，所以后退按钮会撤销您最后按下的那个，您复制的地址会显示您当时的列表。只有在有列表可缩小时才会显示它们，所以没有赛事的年份不显示。

按钮下面的**国家**、**地区**和**运动**列表会进一步缩小按钮留下的结果，所有人都是如此。它们只提供该列表中有的选项，所以任何选择都不会让您得到空结果。

## 您能对赛事做什么

对于您只负责其排名的赛事，列表只提供**选手**，没有别的。它会打开该赛事的页面，您可以在那里修改其任何选手的世界排名名称，查看其管理者，并用**给管理者发邮件**写信给他们，还可以从**排名**标签页取用该赛事用于世界排名的比赛。您不能修改赛事、将其归档或在其中录入成绩，因为这些属于它的管理员和记分员。这类已归档赛事没有按钮，但点它的名称仍会打开它的页面。

对于您管理或记分的赛事，列表提供任何管理员或记分员都有的功能：**管理**，带有铅笔（**编辑**）和垃圾桶（**归档**），或者**成绩**。身为负责人并不改变其中任何一项。
