# 新功能

## 发布于 2026-10-30

### iPad

现在，在首页按下列表和按下空白处都能正常工作了。我用 iPad 6 测试了每一个页面，没有出现任何问题，希望所有 iPad 和 iMac 也都如此。无论结果如何，都请告诉我。

### 查找内容

- **国家、地区和运动又变回列表。** 首页和年份页面上用来筛选赛事的栏位，改回浏览器自带的列表：按一下就能看到所有名称并从中选择。在栏位里输入的效果不够好。

### 管理赛事

- **国家、地区和运动又是列表。** 创建或更改赛事的表单也用列表来选择，选手或队伍的旗帜同样从列表中选择。
- **旗帜按国家的顺序排列。** 澳大利亚、埃及、英格兰、新西兰、西班牙和美国排在最前，然后是 2025 年以来举办过赛事的其他国家，最后是其余所有国家。在美国之后和威尔士之后各画一条线，表示一组到此结束、下一组开始。

### 赛事所在国家

Chris Williams 又帮了忙，他帮我改进了从旧数据库迁移时赛事的所在国家。

## 发布于 2026-10-29

### 查找内容

- **输入国家、地区或运动。** 首页和年份页面上用来筛选赛事的栏位，现在是可以输入的框，不再是要滚动的列表。输入名称的一部分，例如“西兰”，含有它的名称就会被提示出来。点按框末尾的箭头，或按向下箭头键，可以看到所有名称，每次显示五个，其余的滚动查看。点按某个提示，或用方向键移动后按 Enter 键，即可选中。框留空表示不限。不是国家或运动名称的文字不能留在框里：系统会请您选择一个，按 Escape 键则会恢复您原来选的那个。
- **选手页面上，每个赛事的日期保持在同一行。** 在手机上，选手页面里各个赛事的日期以前会折成两行。现在它们保持在一行，换行的是赛事的名称。

### 管理赛事

- **通过输入来选择国家、地区和运动。** 创建或更改赛事的表单也用同样的框来填写这些。赛事必须有国家和运动，所以要先选择一个，才能离开其中任一个框或提交表单。更正国家名称的文字，不会再丢掉您已选的地区。换选另一个国家则会清除它。
- **旗帜也是输入的。** 选手或队伍的旗帜用同样的方式选择。框留空表示没有旗帜。
- **会提示选手所代表的对象。** 输入选手所代表的对象时，会提示已有选手以其为代表被添加过的俱乐部和国家，不限赛事，也不限运动。输入两个字母即开始提示。最多提示十个，按字母顺序排列，只有大小写不同的名称只提示一次，按它最初的写法。已归档的选手和队伍中的选手不在查找之列。
- **帮助说明了小组的轮数。** 轮数是小组中每一对选手相遇的次数，每一轮各打一场比赛。它一开始是 1，小组几乎总是用 1。只有在选手要再次相遇的小组中才调高，比如双循环赛。“项目”一页已经写明，小组和瑞士制现在各有一节。

### 从旧网站迁移过来的赛事

- **更多差点会从世界排名姓名中去掉。** 旧网站上选手最后一个空格之后的数字，无论是整数还是带小数如 5.5 或 5,5，带不带加号或减号，在查找其世界排名时，不再被当作姓名的一部分。分号之后的差点也一样，如 Tim Murphy; 5.5。末尾有两个数字的，如 Tim Murphy 3 5，则保持原样，因为无从知道指的是哪一个；整个名字只是一个数字的，也一样。

## 发布于 2026-10-28

### 查找内容

- **搜索结果改为表格。** 搜索找到的赛事和项目，现在排版得和首页的列表一样：比赛进行的日期、运动类型、所在国家的旗帜，以及名称。项目会显示它所属赛事的日期、运动类型和旗帜，以及它所在的赛事。日期和名称都可以排序，每个表格各自排序，排序方式会和您输入的内容一起保留在页面地址里。排序只会重新排列显示出来的一百条结果，它们是与您的搜索词最匹配的，并不是全部匹配项。
- **最热门的国家排在最前。** 无论在哪里选择国家，列表现在都先列出澳大利亚、埃及、英格兰、新西兰、西班牙和美国，然后是 2025 年以来举办过赛事的其他国家，最后是所有其余国家，三组之间有一条线隔开。
- **每个赛事都显示它的运动。** 在平板或更宽的屏幕上，首页和年份页面的赛事列表会在日期之后，用一个简短的代码显示赛事的运动，例如 GC 或 AC，每种运动有各自的颜色。在手机上不显示代码，以便给名称留出空间。
- **首页。** 首页即将举行的赛事，现在在任何宽度下都位于近期结果的下方。
- **旗帜不再挤占手机屏幕。** 在手机上，所有赛事列表都不再显示旗帜那一列，名称有了更多空间。
- **国家列表在 Linux 版 Chrome 中保持打开。** 以前在首页点按国家栏，列表会打开后立刻又关上。现在它会保持打开，并且可以滚动。

### 关注赛事

- **差点。** 赛事管理员现在可以给选手设定差点，例如 4、+4 或 -1.5。它显示在选手姓名之后，如果有所代表的对象，也一并显示，如 Tim Murphy (4, 澳大利亚)。
- **瑞士制表格中的剥离分。** 瑞士制表格中的每个结果，现在末尾都会写上该局的剥离分，排名文本文件里本来就是这样。一局以 26tp 对 17 获胜，胜者显示 +9tp，负者显示 -9tp。没有剥离分的对局，显示与以前相同。

### 从旧网站迁移过来的赛事

- **更多赛事回到了正确的国家。** 许多赛事迁移过来时国家不对，因为旧网站只知道时区。现在网站会尽可能从赛事名称中读出国家，例如 Irish、Welsh、Bayfield 或 CroqCan，并把每场英格兰对苏格兰的比赛放在当年的东道国。感谢 Chris Williams 的帮助。
- **尚未举行的赛事也会迁移过来**，即使它们的管理员还没有添加项目，这样您就能查到赛事的时间和地点。
- **旧网站上选手姓名后的差点**，如 Tim Murphy 1，在查找其世界排名时，不再被当作姓名的一部分。

## 发布于 2026-10-27

Croquet Scores 已用 AI 以 TypeScript 完全重写。下面是您会注意到的变化。

### 查找内容

- **搜索。** 每个页面顶部都有搜索框。输入名字，按“搜索”，就能找到赛事、项目和选手。结果分成三个列表，没有内容的列表不会显示。如果某一类结果超过一百条，页面会告诉您；在搜索词里再加一个词，就能缩小范围。
- **按国家、地区和项目筛选赛事。** 在首页选择一个国家，就只看在该国举办的赛事。选定国家后，还可以选择它的州或省，也可以再选一个运动。您的选择会保留在页面地址里，所以可以收藏或发给别人，点后退按钮即可撤销。**选择州或省只能找到新的赛事。** 较早的赛事没有填写州或省，所以选了之后它们会被排除。

### 关注赛事

- **管理者的通知。** 赛事的管理者现在可以写通知，告诉选手比赛进行中需要知道的事：赛制、比赛顺序的变动、午餐的时间。通知在赛事新增的“通知”栏目里，最新的在最前面，并显示每条是多久以前写的。
- **星号（\*）标出您还没读的内容。** 一条通知在您打开之前都带有星号；您读过之后如果它被修改，星号会再次出现。只要有任何一条通知未读，赛事每个页面上的“通知”栏目也会带星号，所以不用点进去就知道有新消息。评论也用同样的方式标记。您的浏览器会记住您读过什么，所以不需要登录。换一部手机或电脑，则一条都不算读过。
- **评论更容易跟着看。** 在旧网站上，每来一条新评论，页面就会被拉到最底部，回头翻看早先评论的人会找不到刚才的位置。现在只有在您本来就停在底部、正在看最新评论时，页面才会跟着滚到新评论。如果您已经往回翻去看更早的评论，页面就不会动。

### 网站

- **您的语言。** 网站现在有十七种语言：Afrikaans、العربية (مصر)、中文、Nederlands、English、Français、Deutsch、Italiano、日本語、한국어、Te Reo Māori、Polski、Português、Русский、Español、Svenska 和 Cymraeg。网站会显示您的浏览器所要求的、且网站有的第一种语言；如果一种都没有，就显示英语。想换成别的语言，请使用任意页面底部页脚里的列表，并按旁边的按钮。如果您希望增加某种语言，请发邮件到 <croquetscores@gmail.com>。
- **浅色或深色。** 同样在页脚：选择“浅色”、“深色”或“跟随系统”。“跟随系统”会随您的手机或电脑而定。网站会在每个页面、每次访问时记住您的选择。
- **您用的是哪个版本。** 页脚现在会显示您正在看的网站版本，例如 v234。如果您要报告问题，请说明是哪个版本。
