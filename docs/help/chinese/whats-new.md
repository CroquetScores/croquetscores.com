# 新功能

## 发布于 2026-10-19

Croquet Scores 已用 AI 以 TypeScript 完全重写。下面是你会注意到的变化。

代码现已开源，采用 GNU Affero 通用公共许可证第 3 版（AGPL-3.0）。任何人都可以阅读、使用和修改它；任何人如果把修改过的版本作为网站运行，就必须以同一许可证公开自己的修改。

### 查找内容

- **搜索。** 每个页面顶部都有搜索框。输入名字，按“搜索”，就能找到锦标赛、赛事和选手。结果分成三个列表，没有内容的列表不会显示。如果某一类结果超过一百条，页面会告诉你；在搜索词里再加一个词，就能缩小范围。
- **按国家、地区和项目筛选锦标赛。** 在首页选择一个国家，就只看在该国举办的锦标赛。选定国家后，还可以选择它的州或省，也可以再选一个项目。你的选择会保留在页面地址里，所以可以收藏或发给别人，点后退按钮即可撤销。**选择州或省只能找到新的锦标赛。** 较早的锦标赛没有填写州或省，所以选了之后它们会被排除。

### 关注锦标赛

- **管理员的备注。** 锦标赛的管理员现在可以写备注，告诉选手比赛进行中需要知道的事：赛制、比赛顺序的变动、午餐的时间。备注在锦标赛新增的“备注”栏目里，最新的在最前面，并显示每条是多久以前写的。
- **星号（\*）标出你还没读的内容。** 一条备注在你打开之前都带有星号；你读过之后如果它被修改，星号会再次出现。只要有任何一条备注未读，锦标赛每个页面上的“备注”栏目也会带星号，所以不用点进去就知道有新消息。评论也用同样的方式标记。你的浏览器会记住你读过什么，所以不需要登录。换一部手机或电脑，则一条都不算读过。
- **评论更容易跟着看。** 在旧网站上，每来一条新评论，页面就会被拉到最底部，回头翻看早先评论的人会找不到刚才的位置。现在只有在你本来就停在底部、正在看最新评论时，页面才会跟着滚到新评论。如果你已经往回翻去看更早的评论，页面就不会动。

### 网站

- **你的语言。** 网站现在有十七种语言：Afrikaans、العربية (مصر)、中文、Nederlands、English、Français、Deutsch、Italiano、日本語、한국어、Te Reo Māori、Polski、Português、Русский、Español、Svenska 和 Cymraeg。网站会显示你的浏览器所要求的、且网站有的第一种语言；如果一种都没有，就显示英语。想换成别的语言，请使用任意页面底部页脚里的列表，并按旁边的按钮。如果你希望增加某种语言，请发邮件到 <croquetscores@gmail.com>。
- **浅色或深色。** 同样在页脚：选择“浅色”、“深色”或“跟随系统”。“跟随系统”会随你的手机或电脑而定。网站会在每个页面、每次访问时记住你的选择。
- **你用的是哪个版本。** 页脚现在会显示你正在看的网站版本，例如 v234。如果你要报告问题，请说明是哪个版本。
