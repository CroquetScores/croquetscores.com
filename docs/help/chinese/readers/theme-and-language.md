# 选择主题和语言

这两项设置都在每个页面的底部，而且都会被记住，所以只需要设置一次。

## 主题

**主题**有**浅色**、**深色**和**跟随系统**三个选项。在你做出选择之前，用的是**跟随系统**：你的手机或电脑是深色时，本站就是深色，否则就是浅色。选择**浅色**或**深色**，则无论你的设备怎样，本站都保持那样。

## 语言

在你选择之前，本站会使用你的浏览器声明你能阅读、而本站也提供的第一种语言。如果一种都没有，就使用英语。

要换成别的语言，请在**语言**列表中选好，然后按**更改**。页面会用那种语言重新显示，之后的每个页面也一样，这次访问和下次访问都是如此。列表打开时停在你正在使用的语言上。

如果本帮助的某个页面还没有翻译成你的语言，就会显示英语版，而不是什么都不显示。

## 如果设置被忘记了

本站把每项设置记在 Cookie 里，所以清除 Cookie 或设置为不保存 Cookie 的浏览器会忘记设置，并再次请你选择。[脚本和 Cookie](scripting-and-cookies.md)说明了本站保存什么。
