# 排名

赛事计入世界排名时，它的比赛结果会以文件的形式发送给世界排名，这个文件由网站根据您录入的内容为您生成。**排名**标签页就是您取得它的地方。

## 标签页

打开赛事的页面，选择**排名**，它是所有标签页中的最后一个。它会说明这个文件是什么：协会槌球是文本文件，高尔夫槌球和美式六门槌球是电子表格。它会说明还有哪些事要您手动完成，以及之后要把文件发送给世界排名负责人。在这下面是**下载用于世界排名的比赛**，用来保存文件。在录入任何一个成绩之前它就在那里，在有成绩之前，给出的是一个空文件。

这个标签页只出现在计入世界排名的赛事的页面里，并且只向它的管理者显示：记分员看不到。文件本身位于赛事自己的地址后面加上 `/rankings`，例如 `/2026/ac/spring-open/rankings`，这是网站一直给它的地址，任何知道这个地址的人都可以打开。

## 文件里有什么

每个已录入且未归档的成绩都在里面，按录入的顺序排列，包括已撤销的成绩，以及已退赛选手的成绩。已归档的成绩不在其中。靠轮空或不战而胜赢下的比赛并没有打过，所以没有对应的一行。

选手以其世界排名姓名列出，没有另给姓名的，就是他们的姓名。

**协会槌球**为每个有成绩的项目各设一个区块：它的活动、日期、获胜者、是比赛还是单局，以及每个结果各一个带编号的行，例如“1 Sam Someone beat Alex Another +9”。成绩是胜者的球门数减去负者的球门数，胜者得分更多时带加号，后面再跟剥夺数。淘汰赛的一场比赛占一行，其中依次是每一局的成绩。网站只能推测谁赢得了项目，所以请检查每个区块的 **Winner** 一行（这一行的措辞是英文），并在把文件发出去之前改正它。

**高尔夫槌球和美式六门槌球**是一份电子表格：赛事的名称、它的日期和共有多少局，然后每一局各一个带编号的行，依次是胜者的姓和名、“beat”、负者的姓和名，以及两个成绩。淘汰赛一场比赛中的每一局各占一行。在最后一行下面，**Tournament winner:** 一行（这一行的措辞是英文）是空着的，留给您填写。

## 没有文件的时候

不计入世界排名的赛事没有文件。打开它的排名地址，会看到一个页面，说明这一点和原因：它的运动没有世界排名，它使用差点，它允许平局，或者它被勾选为不计入。这是在创建赛事时设定的，并通过**编辑**更改。
