# 备注

锦标赛页面的**备注**标签页是管理员在锦标赛进行期间写下选手需要知道的事的地方：赛制、比赛顺序的变动、午饭时间。读者在锦标赛的公开“备注”页面上找到它们，他们尚未阅读的备注在那里以红色星号标出，在他们打开之前，锦标赛每个页面上的“备注”栏目也以红色星号标出。

![“备注”标签页，有两条备注](../../../english/tournament-managers/standard-tournament/images/notes-tab.png)

## 撰写备注

按列表上方的**添加备注**。一个面板取代列表的位置，因为备注写起来篇幅较长，需要空间。

![备注面板，停在“编写”标签页上](../../../english/tournament-managers/standard-tournament/images/note-panel.png)

**标题**是必填的，备注按它列出。它是纯文本。

**说明**以 Markdown 书写，当标题已经说完要说的一切时可以留空。文本框上方的工具栏为你书写 Markdown：标题、粗体、斜体、引用、代码、链接、编号列表、项目符号列表和任务列表。每个工具作用于选中的内容，或者选中的每一行的开头，或者把光标放到该填词的位置。

**预览**按读者在备注页面上看到的样子显示备注。

![备注面板，停在“预览”标签页上](../../../english/tournament-managers/standard-tournament/images/note-preview.png)

按**添加**。备注被保存，列表回来并把它放在最上面，它立刻就出现在公开的“备注”页面上。

## 编辑备注

按备注的标题或其**编辑**，在该备注上打开面板。按**保存**保存更改。读者读过之后又被编辑的备注会再次为他们标出。

## 删除备注

不再适用的备注就删除。删除的备注一去不返，所以**删除**会先询问。

![删除备注之前所问的问题](../../../english/tournament-managers/standard-tournament/images/delete-note-asks.png)
