# 选手

赛事页面的**选手**标签页是录入、更正、排序和搁置选手的地方。它是页面打开时所停的标签页，因为录入选手是对一个赛事所做的第一件事。

选手在这里录入一次，进入赛事。每位选手参加哪些项目是之后在每个项目自己的页面上，从这里录入的选手中选择的。见[把选手录入项目](entering-players-in-a-competition.md)。

![“选手”标签页，已录入若干选手，其中一位已归档](images/players-tab.png)

## 添加选手 {#add-a-player}

按列表上方的**添加选手**。一个对话框覆在页面上打开。

![填好的“添加选手”对话框](images/add-player-dialog.png)

**姓名**是必填的。它是选手在每个页面上显示的姓名，长度在 3 到 254 个字符之间。同一个赛事中的两位选手不能同名，无论大小写如何；如果两位选手确实同名，就在姓名本身里把他们区分开，如“Andrew Hobbs (2)”。

**代表**是选手所代表的对象，按读者的说法书写：一个俱乐部、一个地区或一个国家，如“Canterbury Croquet Club”。它显示在姓名后面的括号里。可以留空。

**旗帜**是显示在选手姓名旁边的旗帜。可以保留为无，大多数选手都是如此。选手代表什么和他们举什么旗帜是分开保存的，因为一位选手可以为一个国家的俱乐部效力，却举另一个国家的旗帜。

**世界排名选手姓名**是世界排名所知的该选手的姓名。只在协会槌球或高尔夫槌球的赛事中询问，这是世界排名备有选手名单的两个运动。美式六门槌球的选手在排名中就是以本名为人所知，所以那里不询问，每位选手的世界排名姓名始终就是他的姓名。在您添加选手时，它会跟随您输入的姓名，因为大多数选手在排名中就是以本名为人所知的，而一旦您在其中输入，它就不再跟随。留空时，保存为选手的姓名。

当您输入姓名时，会提供世界排名所知的、姓名以此开头的选手，这样您可以直接取用排名中的拼法而不必打完。在世界排名姓名旁边，一个对勾表示排名知道这个姓名，一个问号表示不知道：姓名可能拼错了，或者该选手是排名中的新人。这只是提示。排名不知道的姓名和知道的姓名一样会被保存。

按**添加**。选手被添加，对话框说明了这一点，各字段清空以便录入下一位选手，光标回到姓名处。用这种方式添加完整份名单，然后按**取消**关闭对话框。取消不会保存任何尚未添加的内容。

![添加一位选手之后的对话框](images/add-player-dialog-added.png)

选手绝不能叫“Bye”。淘汰赛的轮空在淘汰赛自身录入选手的地方添加，所以第一个词是英文“bye”的姓名会被拒绝，对话框会说明原因。

## 批量添加选手 {#adding-multiple-players}

要一次添加整份名单，按**批量添加选手**，它在**添加选手**旁边。一个对话框覆在页面上打开，里面有一个可输入多行文字的框。您可以从电子表格复制名单，粘贴到框里。

**第一行写明各字段**，用逗号或制表符分隔：**Name**，以及 **Representing**、**Flag**、**Handicap** 和 **WorldRankingPlayerName** 中的任意几个，顺序不限。无论网站使用哪种语言，这些字段名都用英文输入。**Name** 必须在其中。**之后的每一行是一位选手**，按同样的顺序为每个字段给出一个值，用同样的方式分隔。选手某个字段没有内容时，就让它空着，但保留逗号或制表符。例如，用逗号：

```
Name,Representing,Flag
Sam Someone,Canterbury Croquet Club,New Zealand
Alex Another,,England
```

- **姓名、代表和世界排名选手姓名**与添加单个选手时遵循同样的规则（见[添加选手](players.md#add-a-player)）。姓名长度在 3 到 254 个字符之间，不能与赛事中已有的姓名相同（无论大小写如何），也不能是“Bye”。
- **旗帜**是国家或地区的名称，用您的语言书写，与“添加选手”对话框的列表所提供的一致，如新西兰。
- **差点**是带符号的数，最多两位整数和一位小数，如 4、+4 或 -1.5。
- 没有给出 **WorldRankingPlayerName** 的选手，以其姓名为人所知，与逐个添加时一样。
- **逗号或制表符。**从电子表格复制的单元格以制表符分隔，手工输入的名单通常以逗号分隔。两种都可以。如果第一行里有制表符，整份名单就按制表符读取，否则按逗号读取。
- 含有分隔符的值要用双引号括起来，就像电子表格那样写：在以逗号分隔的名单中写成“Smith, John”。值里面的引号要写两次。
- 每个值两端的空格会被去掉，没有任何内容的行会被忽略。
- 一份名单最多容纳 500 位选手。其余的放到另一份名单里添加。

按**添加**。整份名单会先检查，通过后才会保存，所以名单里有任何错误，就不会添加任何人。错误会显示在框的下方，指明在哪一行，第一行算作第 1 行。每个错误都会列出，而不只是第一个，您输入的内容也会保留，方便您改正。名单保存后，对话框关闭，**选手**标签页按您写的顺序列出新选手。与停留以便添加下一位选手的**添加选手**不同，这里没有下一位：名单就是下一位。

对话框标题栏中的 **?** 会带您来到这里。

## 更正选手 {#correcting-a-player}

按选手的姓名或其**编辑**，在该选手上打开同一个对话框，标题为“编辑选手”。改正错误之处并按**保存**，这会保存更改并关闭对话框。姓名被更正的选手保留原有的世界排名姓名，因为排名仍然以此知道他们。在美式六门槌球中，选手的世界排名姓名始终就是他的姓名，所以更正姓名也就更正了它。

![“编辑选手”对话框](images/edit-player-dialog.png)

在这里更正的选手处处都被更正：在他们参加的每个项目中，以及在每个公开页面上。

## 给选手排序

选手按赛事的顺序列出，这也是他们被录入项目时提供的顺序，以及淘汰赛抽签的顺序。每行末尾的箭头**上移**和**下移**，把选手移动一位。第一位选手没有“上移”，最后一位没有“下移”。

## 归档选手 {#archiving-a-player}

**归档**把选手搁置一旁：误录的，或者退出整个赛事的。已归档的选手列在**已归档的选手**下，加上删除线，排在正在使用的选手之后，并且只提供**恢复**。已归档的选手不在任何项目中，也不出现在任何公开页面上。

打过任何一局的选手不能归档，因为那样一来那些局就成了与一个已不存在的人打的，所以这样的选手没有“归档”。只有已归档的局的选手可以归档。

归档一位不在任何项目中的选手不会先询问，因为恢复他们就能把一切放回原处。归档一位在某个项目中的选手会先询问，因为归档会把他们从所参加的每个项目中移除，而恢复他们并不会把他们放回去。

![归档一位参加了项目的选手之前所问的问题](images/archive-player-asks.png)
