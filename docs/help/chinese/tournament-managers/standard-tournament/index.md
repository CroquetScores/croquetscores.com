# 运作标准赛事

标准赛事是由逐个录入的选手之间进行的赛事：俱乐部周末赛、公开赛、冠军赛。它的选手被录入到小组赛、淘汰赛和瑞士制中，成绩随着比赛的进行逐一发布。这份指南带领管理者从登录开始，直到赛事的成绩向公众开放。

它自成一体。其中没有任何内容依赖于团体赛事的指南，那份指南是另外写的。

## 开始之前

您需要一个账户。点击[这里](/account/register)注册账户。

管理者所做的一切都在网站的管理后台中进行。选手和观众关注赛事的公开页面，取自管理后台所保存的内容，所以不需要另行发布：录入一个成绩，它立刻就出现在公开页面上。

## 各页的顺序

1. [创建赛事](creating-a-tournament.md)：它的名称、日期、运动、举办地点，以及它计入什么。
2. [选手](players.md)：录入赛事的选手，更正他们，以及把误录的选手搁置一旁。
3. [项目](competitions.md)：添加小组赛、淘汰赛和瑞士制，并排好顺序。
4. [把选手录入项目](entering-players-in-a-competition.md)：每个项目由谁参加、淘汰赛中的轮空、结转、移除和退赛。
5. [成绩](scores.md)：录入结果，更正它们，以及把误录的结果搁置一旁。
6. [通知](notes.md)：在赛事进行期间告诉选手他们需要知道的事。
7. [管理者和记分员](managers-and-scorers.md)：分担赛事的运作，以及让某人只能录入成绩而不能更改其他任何东西。
8. [排名](rankings.md)：发送给世界排名的文件，以及留给您填写的部分。
9. [更改、归档和恢复赛事](changing-and-archiving.md)：更正赛事的详情，以及把赛事搁置一旁。
10. [公众看到什么](what-the-public-sees.md)：您的选手关注的页面，以及您录入的内容如何在那里显示。

## 管理后台的布局

管理后台的首页列出您参与的赛事，一次显示一年。

![管理后台中的赛事列表](images/admin-list.png)

按赛事的名称或**管理**，打开它的页面。所有要运作的东西都在它名称下方的六个标签页里：**选手**、**项目**、**通知**、**管理者**、**记分员**和**排名**。页面打开时停在“选手”上，因为选手是最先录入的东西。

![一个赛事的页面，停在“项目”标签页上](images/tournament-page.png)

页眉下方的深绿色条用于在页面之间移动。它以**赛事**通向赛事本身，并以名称通向它的每个项目，这样您就能从赛事去到某个项目、在项目之间来回，而不必回到“项目”标签页。您所在的页面以黑色标出。

## 处处适用的规则

**除通知以外，没有任何东西会被直接删除。**选手、项目、成绩和赛事本身都是归档而不是删除：搁置一旁，加上删除线，列在一个单独的标题下，并带有**恢复**以把它们找回来。归档、恢复以及上移下移从不要求您确认，因为每一个都可以通过反向操作撤销。无法撤销的事，比如把选手从项目中移除或删除通知，会先询问。

**覆在页面上的对话框在您按下它的按钮之前不会保存任何东西。**取消，或 Escape 键，会关闭它并让一切保持原样。添加东西的对话框，比如“添加选手”和“添加成绩”，在每添加一项之后仍保持打开，这样可以一项接一项地录入整份名单。

**被拒绝的内容会在相关字段旁边说明。**被拒绝的内容不会保存，而您输入的内容仍然保留，这样可以直接改正而不必重新输入。

**管理后台可以在手机上使用。**每个按钮都足够大，可以用拇指按下，并且没有任何东西比屏幕更宽。
