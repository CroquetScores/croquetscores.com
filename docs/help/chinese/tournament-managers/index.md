# 锦标赛管理员帮助

本站的锦标赛由它的管理员在管理后台运作：创建它的人，以及此后被他们设为管理员的任何人。这些指南说明怎样做，从登录开始，直到锦标赛的成绩向公众开放。

锦标赛分两种，每种各有一份指南。每份指南自成一体，所以你只需读你正在运作的那种锦标赛的指南，其他的不用看。

- [运作标准锦标赛](standard-tournament/index.md)：由逐个录入的选手之间进行的锦标赛，分为小组赛、淘汰赛和瑞士制。俱乐部周末赛、公开赛、冠军赛都属于这种。
- [运作团体锦标赛](teams-tournament/index.md)：由队伍之间进行的锦标赛，以两方之间的对抗赛进行，对抗赛由双方选手之间的比赛组成。系列对抗赛、州际盾牌赛、世界团体锦标赛都属于这种。

一个锦标赛属于哪一种，由创建时的**赛制**决定：标准属于第一种；团体、Eire Cup、Interstate Shield 或 GC World Team Championship 属于第二种。
