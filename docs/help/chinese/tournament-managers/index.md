# 赛事管理者帮助

本站的赛事由它的管理者在管理后台运作：创建它的人，以及此后被他们设为管理者的任何人。这些指南说明怎样做，从登录开始，直到赛事的成绩向公众开放。

赛事分两种，每种各有一份指南。每份指南自成一体，所以您只需读您正在运作的那种赛事的指南，其他的不用看。

- [运作标准赛事](standard-tournament/index.md)：由逐个录入的选手之间进行的赛事，分为小组赛、淘汰赛和瑞士制。俱乐部周末赛、公开赛、冠军赛都属于这种。
- [运作团体赛事](teams-tournament/index.md)：由队伍之间进行的赛事，以两方之间的对抗赛进行，对抗赛由双方选手之间的比赛组成。系列对抗赛、州际盾杯、高尔夫槌球世界团体锦标赛都属于这种。

一个赛事属于哪一种，由创建时的**赛制**决定：标准赛制属于第一种；团体赛、爱尔兰杯、州际盾杯或高尔夫槌球世界团体锦标赛属于第二种。
