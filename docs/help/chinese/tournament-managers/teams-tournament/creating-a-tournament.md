# 创建锦标赛

在管理后台的锦标赛列表上方按**新建锦标赛**。它放在列表上方而不是下方，这样很长的列表也不会把它推出手机屏幕之外。

![为团体锦标赛填好的新建锦标赛表单](images/new-tournament.png)

表单询问锦标赛开始时所需的一切。这里最要紧的是**赛制**，正是它使一个锦标赛成为团体锦标赛。

## 表单询问什么

**名称。**读者用来找到锦标赛的东西，比如“Trans-Tasman Tests”。长度在 3 到 254 个字符之间。全部小写或全部大写的名称会被拒绝，因为它在显示的每个页面上都会看起来像一个错误。两个锦标赛可以同名，因为同一个锦标赛每年都会举办。

**开始**和**结束。**锦标赛进行的日期。每场对抗赛都在这段日期之内进行，所以要把它们设得覆盖整个赛事。锦标赛不能在开始之前结束，也不能在明年年底之后开始或结束。锦标赛属于它开始的那一年，这也是它地址中的年份。

**赛制。**选择团体赛制之一：

- **团体**是任何队伍间赛事的通用赛制。
- **Eire Cup**、**Interstate Shield** 和 **GC World Team Championship** 是特定的赛事，各自作为一种单独的赛制保存，以便按该赛事的运作方式来运作。

标准是唯一不属于团体的赛制，不是你在这里想要的。Gateball Scores 不提供赛制，因为那里的每个锦标赛都是门球的标准锦标赛；团体锦标赛在 Croquet Scores 上创建。

**项目。**网站提供的运动项目，按它的顺序：协会槌球、高尔夫槌球、美式六门槌球和 Ricochet。

**国家或地区**和**地区。**锦标赛的举办地。只有当你选择的国家划分为地区时才会询问地区，比如澳大利亚的各州，即使这时也可以不选。

**副标题。**任何你想让读者知道、却没有专属字段的内容：在哪里停车、几点吃午饭、找谁联系。它显示在每个公开页面上锦标赛名称的下方。它以 Markdown 书写，所以在一个词两边加上星号可以把它变成粗体，每行开头加一个短横线可以做成列表。最多 2000 个字符，可以留空。

**采用让分。**让分赛事请勾选此项。

**允许平局。**当一局可以在双方都不是胜者的情况下结束时勾选此项。勾选时，录入的得分相等且没有标记的比分会作为平局保存；未勾选时，得分相等的一局必须在胜者得分后面加上标记来说明谁赢了，比如“6w”。

**打平的对抗赛算平局。**只在选择了团体赛制之后才询问。对抗赛由赢得更多比赛的队伍获胜，比赛数相等的对抗赛由净胜局决定，再由净胜球门决定，除非勾选此项，这时比赛数相等的对抗赛算作平局，有些团体赛事就是这样规定的。对于团体赛制它一开始未勾选，对于 GC World Team Championship 则一开始勾选，因为那项赛事一直把打平的对抗赛算作平局。

**计入世界排名。**只在可以计入时才询问：协会槌球、高尔夫槌球或美式六门槌球的锦标赛，既不采用让分也不允许平局。它一开始是勾选的。

**全国级赛事**和**国际级赛事。**锦标赛可以是其中之一，或者两者都不是，但绝不能两者都是：勾选一个会取消另一个的勾选。

## 创建它

按**创建锦标赛**。你会被带到锦标赛在管理后台中的页面，停在它的“队伍”标签页上，而你是它的第一位管理员。它列在管理后台中它开始的那一年下。

![一个新创建的锦标赛，还没有队伍](images/tournament-page-empty.png)

锦标赛的公开地址由它的年份、项目和名称组成，如 `/2026/ac/trans-tasman-tests`。之后更正名称时它保留这个地址，这样已经发出去的链接仍然能找到它；只有当它开始的年份或项目改变时它才会移动。

## 如果有内容被拒绝

被拒绝的内容会在相关字段下方说明，而你输入的内容仍然保留。在每个字段都被接受之前，不会保存任何东西。最常被拒绝的是全部小写的名称、早于开始日期的结束日期，以及没有选择国家或地区。
