# 账户帮助

阅读赛事不需要账户。运作赛事和在本站发表内容才需要。这些指南说明怎样拥有一个账户，从注册到注销。

- [注册并确认您的电子邮件地址](registering.md)：组成账户的两个步骤，以及邮件没有收到时怎么办。
- [登录](signing-in.md)：用密码或用 Google 登录，以及无法登录时怎么办。
- [密码](passwords.md)：密码必须满足什么要求、选密码的建议，以及本站怎样检查密码。
- [管理您的账户](looking-after-your-account.md)：您的姓名、您的电子邮件地址，以及让账户被忘记。

每篇指南都可以单独阅读，您只需读自己需要的那一篇。
