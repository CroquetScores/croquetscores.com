# 登録とメールアドレスの確認

アカウントは二つのステップで作ります。まずメールアドレスを伝え、次にそのアドレスに届くリンクを開いて、自分のものであることを示します。名前とパスワードは、二つ目のステップで尋ねます。

## 登録

**アカウント**メニューの**新規登録**を選びます。ページで尋ねるのは**メールアドレス**だけです。サイトに書き込む内容についての**利用規約に同意します**にチェックを入れて、**登録する**を押します。パスワードが要らない**Googleで登録**または**Facebookで登録**を押すこともできます。詳しくは[サインイン](signing-in.md)をご覧ください。

登録するには、このサイトでスクリプトを有効にしておく必要があります。サイトが人とプログラムを区別するためです。無効になっている場合は、何かを入力する前にその旨が表示されます。詳しくは[スクリプトと Cookie](../readers/scripting-and-cookies.md)をご覧ください。

次のページには**メールをご確認ください**と表示されます。アドレスの持ち主が誰であっても同じ内容が表示されるので、どのアドレスにアカウントがあるかを他人に知られることはありません。数分たっても何も届かない場合は、迷惑メールフォルダを確認してください。

## 確認

メールに書かれたリンクを開きます。すぐには確認されず、フォームが開きます。メールシステムは確認のためにメール内のリンクをたどることがあり、アドレスはメールを読んだ人だけが確認すべきだからです。

フォームでは、**名前**と**パスワード**を入力します。パスワードは二度入力し、二度目は**パスワード（確認）**に入力します。パスワードに求められることは[パスワード](passwords.md)をご覧ください。**メールアドレスを確認する**を押します。

リンクは別の端末で開くことが多いので、確認してもサインインした状態にはなりません。メールアドレスが確認されたことが表示され、**サインイン**へ案内されます。

## リンクが使えなくなったとき

リンクが使えるのは24時間です。それを過ぎると期限切れと表示されるので、**新しいリンクを送る**を押すと、同じアドレスに新しいリンクが届きます。新しいリンクを求められるのは1時間に3回までで、登録で送られるメールもこの回数に数えます。

改ざんされたなど、ほかの理由でリンクが使えない場合は、使えないとだけ表示されます。すでに確認済みの場合は、その旨とサインインへの案内が表示されます。

## 登録したのが自分ではないとき

登録ページには、誰でも好きなアドレスを入力できます。覚えのないメールが届いたら、無視してください。リンクを開いてフォームに入力しない限り、アカウントは確認されません。
