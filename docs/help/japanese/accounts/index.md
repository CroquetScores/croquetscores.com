# アカウントのヘルプ

大会を読むのにアカウントは要りません。大会を運営するときと、サイトに書き込むときに必要です。このガイドでは、登録から削除まで、アカウントの扱い方を説明します。

- [登録とメールアドレスの確認](registering.md)：アカウントを作る二つのステップと、メールが届かないときの対処。
- [サインイン](signing-in.md)：パスワード、Google、または Facebook でのサインインと、サインインできないときの対処。
- [パスワード](passwords.md)：パスワードに求められること、選ぶときのアドバイス、サイトによる確認の仕組み。
- [アカウントの管理](looking-after-your-account.md)：名前、メールアドレス、そしてアカウントの削除。

各ガイドはそれだけで読めますので、必要なものをお読みください。
