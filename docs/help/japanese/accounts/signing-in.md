# サインイン

**アカウント**メニューの**サインイン**を選びます。サインインの方法は二つあります。

## パスワードで

**メールアドレス**と**パスワード**を入力して、**サインインする**を押します。サインインを求めたページに戻ります。そうしたページがなければ、管理画面に移ります。

どちらかが間違っている場合、ページには、メールアドレスまたはパスワードが正しくないとだけ表示されます。どちらが違うのか、そのアドレスにアカウントがあるのかは表示しません。アカウントを持つ人を調べるのに使われないようにするためです。

1時間に10回サインインに失敗したアドレスは、その1時間が終わるまで制限されます。そのアドレスでサインインしようとすると、正しいパスワードでも、1時間待ってからやり直すように表示されます。これは推測を防ぐための制限です。正しいパスワードを通してしまう制限では、推測する人を止められません。

メールアドレスを確認していないアカウントには、まだパスワードがないので、サインインできません。メールのリンクを開くか、新しいリンクを求めてください。方法は[登録と確認](registering.md)をご覧ください。

## Google または Facebook で

**Googleでサインイン**、**Facebookでサインイン**、**Googleで登録**、**Facebookで登録**は、選んだ Google または Facebook のアカウントを使うので、サイトがそのパスワードを目にすることはありません。この方法で作ったアカウントには、求めるまでパスワードがありません。

Facebook がサイトにメールアドレスを渡すのは、Facebook で確認済みのメールアドレスがあり、その共有を許可している場合だけです。ない場合、サイトはアカウントを見つけることも作ることもできず、その旨をお知らせします。代わりにメールアドレスをお使いください。

パスワードでもサインインできるようにするには、**アカウント**メニューの**パスワードを設定**を選び、**リンクをメールで送る**を押します。リンクはアカウントのメールアドレスに届き、パスワードを忘れたときのリンクと同じようにパスワードを設定できます。

## パスワードを忘れたとき

サインインページの**パスワードをお忘れの方**を押し、メールアドレスを入力して、**再設定の方法を送る**を押します。そのアドレスにアカウントがあってもなくても、ページにはメールを確認するよう表示されます。何が送られるかはアドレスによって違い、読めるのはその持ち主だけです。新しいパスワードを設定するリンク、確認していないアドレスの確認リンク、または登録のリンクのいずれかです。

新しいパスワードを設定するリンクは、1回だけ、1時間使えます。リンクを開き、新しいパスワードを二度入力して、**新しいパスワードを設定する**を押します。新しいパスワードを設定すると、すべての端末でアカウントがサインアウトされます。ほかの誰かが入ったためにパスワードを設定している場合があるからです。そのあと、選んだパスワードでサインインしてください。

再開の方法を求められる回数には制限があります。ページが誰かの受信箱を埋めるのに使われないようにするためです。
