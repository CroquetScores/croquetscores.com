# パスワード

## サイトがパスワードに求めること

メールアドレスを確認するとき、新しいパスワードを設定するとき、パスワードを変更するときなど、パスワードを選ぶ場面ではどこでも、次のことが求められます。

- **12文字以上**であること。
- 同じものを二度入力すること。二度目は**パスワード（確認）**に入力します。
- ほかで**データ漏えいに含まれた**ことのあるパスワードではないこと。

先頭と末尾の空白は、サインインのときと同じく取り除かれるので、うっかり入れた空白で締め出されることはありません。途中の空白はそのまま残るので、いくつかの単語をつなげたパスフレーズにも向いています。

## 良いパスワードの選び方

サイトが求めるのは長さだけで、大文字、数字、記号は求めません。これは現在のアドバイスに沿ったものです。ほかでは使わない長いパスワードは、読みにくくした短いパスワードより、強くて覚えやすいというものです。サイトが従っているのは米国の国立標準技術研究所（NIST）のアドバイスで、[NIST のデジタルアイデンティティに関するガイドライン（パスワード編）](https://pages.nist.gov/800-63-4/sp800-63b.html)で読めます。

要点は次のとおりです。

- **長くしてください。**関係のない単語をいくつか並べると、覚えやすく推測しにくいパスフレーズになります。
- **このサイトだけで使ってください。**二つのサイトで同じパスワードを使うと、安全性は弱いほうのサイトと同じになり、一方で盗まれたパスワードはほかでも試されます。
- **できればパスワードマネージャーに保管してください。**サイトごとに長いパスワードを作り、すべて覚えてくれます。
- **決まった周期では変更しないでください。**ほかの誰かが知っているかもしれないと思ったときに変更し、それ以外では変更しません。

## サイトが漏えいしたパスワードを確認する仕組み

ほかのサイトから盗まれたパスワードの一覧が公開されていて、アカウントに入ろうとする人はまずそれを試します。そのため、パスワードを選ぶとき、サイトは外部のサービスに、そうした一覧に載っているかを尋ねます。このサービスは第三者が運営していて、サイトはこの目的にだけ使います。

パスワードがサイトの外に出ることはありません。サイトはパスワードから、元に戻せない一方向の指紋を作り、その最初の5文字だけをサービスに送ります。サービスは、同じ文字で始まる漏えい済みパスワードすべての指紋の残りの部分を返します。その数は数百件で、サイトはその中から自分のものを探します。つまりサービスに分かるのは、パスワードが数百件のうちの一つだということだけで、どれなのかは分かりません。仕組みについては、[Cloudflare による解説](https://blog.cloudflare.com/validating-leaked-passwords-with-k-anonymity/)をご覧ください。

一覧に載っているパスワードは、その旨のメッセージとともに拒否されるので、別のものを選びます。サービスに接続できないときは、パスワードをいま確認できないため、受け付けも変更もされません。数分たってからやり直してください。送られたリンクは、期限が切れるまで使えます。

## パスワードの変更

**アカウント**メニューの**パスワードを変更**を選びます。ページでは、**現在のパスワード**、**新しいパスワード**、そして新しいパスワードをもう一度**パスワード（確認）**に入力します。サインインしているだけでは足りないので、現在のパスワードを尋ねます。そうしないと、ロックを解除したまま置いた携帯電話を拾った人に、締め出されてしまうからです。

変更すると、このブラウザではサインインしたままで、ほかのブラウザはすべてサインアウトされます。サイトはパスワードが変更されたことをメールアドレスに知らせるので、自分ではない場合に気づけます。現在のパスワードを間違えると、サインインと同じ制限に数えられます。

現在のパスワードを思い出せない場合は、ページから**パスワードをお忘れの方**へ案内されます。
