# 大会運営者向けの新機能

## 公開日 2026-10-25

前回のリリース以降の主な変更点です。それぞれ、その変更を行ったプルリクエストへのリンクが付いています。

- **世界ランキング担当者の大会一覧を、世界ランキングで絞り込めるようになりました。** 担当者の一覧には、担当する競技のすべての大会が並ぶため、読み進めたい量を超えます。**新しい大会**の横に、**運営者/記録係**、**世界ランキング**、**世界ランキング対象外**の3つのボタンが加わりました。ある大会に当てはまるボタンのどれかがオンなら、その大会は一覧に表示されます。そのため、どのボタンも大会を減らすのではなく増やします。オンのボタンにはチェックマークが付き、**運営者/記録係**と**世界ランキング**は最初からオンです。これらのボタンは担当者専用です。ご自分で大会を運営したり記録したりしている場合、一覧はこれまでどおりです。（[#372](https://github.com/CroquetScores/croquetscores.com/pull/372)、[#376](https://github.com/CroquetScores/croquetscores.com/pull/376)）

- **世界ランキング担当者と管理者は、大会の運営者にメールを送れます。** **運営者**タブに**運営者にメールする**が表示されます。これは大会のすべての運営者あての新しいメールを開くリンクで、件名は「Croquet Scores」です。サイトからは何も送信されません。担当者は、担当する競技のどの大会でもこのタブを見られ、運営者を確認して連絡できますが、運営者を変更することはできません。運営者には、誰のメールアドレスも表示されません。[運営者と記録係](../tournament-managers/standard-tournament/managers-and-scorers.md)をご覧ください。（[#369](https://github.com/CroquetScores/croquetscores.com/pull/369)）

- **1日だけの大会は、ランキングファイルではその日付で表します。** 以前は1日の範囲として `3-3.10.26` と書いていましたが、今は `3.10.26` です。世界ランキング自身の一覧が1日だけを書くのと同じ形です。2日以上の大会はこれまでどおりです。[ランキング](../tournament-managers/standard-tournament/rankings.md)をご覧ください。（[#368](https://github.com/CroquetScores/croquetscores.com/pull/368)）

- **以前のサイトから取り込んだ大会が、より忠実になりました。** 世界ランキングのアソシエーションクロッケーとゴルフクロッケーの大会一覧に載っている大会は、タイムゾーンではなく、その一覧の国が使われます（[#366](https://github.com/CroquetScores/croquetscores.com/pull/366)）。さらに2つの変更（[#377](https://github.com/CroquetScores/croquetscores.com/pull/377)）が、次回の取り込みから適用されます。
  - 選手は、各部門が持つ独自の名簿から取り込み、大会の選手の中から正確な名前で探します。以前のサイトは大会の選手を各部門にコピーし、運営者がそのコピーを変更できたため、ダブルスの部門で「Joe Hogan & Levi Franks」として登録されたペアが、Joe Hogan 1人に結び付けられていました。今はそのペアが独立した1人の選手になります。どの部門にも入っていない選手は、取り込まれなくなります。
  - 部門が選手の所属を示した場合、その選手に所属がなければ設定します。その後で別の所属を示した部門があっても、変更しません。2ゲーム先取で保存されていたブロック、またはどのペアも3ゲーム目を戦った3ゲーム先取のブロックは、そのまま保たれます。1ゲーム先取にするのは、あるペアの試合が最後のゲームより前に決まってしまう場合だけで、そのままではサイトが残りを受け付けないからです。

- **裏側の変更。** 取り込みでは、2つの日付の間に始まった大会だけを取り込むよう指定できます（[#374](https://github.com/CroquetScores/croquetscores.com/pull/374)）。また、修正の種類ごとのファイル、エラー用のファイル、取り込みごとの概要を、リポジトリの docs フォルダーに出力して、何を行ったかを示すようになりました（[#377](https://github.com/CroquetScores/croquetscores.com/pull/377) も参照）。取り込みには、ゴルフクロッケーの世界ランキング担当者がさらに4人加わり（[#367](https://github.com/CroquetScores/croquetscores.com/pull/367)）、サイト自身のアドレスはアソシエーションクロッケーの担当者となり、管理者ではなくなりました（[#375](https://github.com/CroquetScores/croquetscores.com/pull/375)）。ときどき失敗したり、サイトに遅れたりしていたシナリオも直しました（[#359](https://github.com/CroquetScores/croquetscores.com/pull/359)、[#373](https://github.com/CroquetScores/croquetscores.com/pull/373)）。

## 公開日 2026-10-23

前回のリリース以降の主な変更点です。それぞれ、その変更を行ったプルリクエストへのリンクが付いています。

- **ハンディキャップ、引き分け、世界ランキングは部門ごとに設定します。** これまでは大会で決めていたため、1つの大会にハンディキャップありのブロックとなしのブロックを並べたり、引き分けのあるテストマッチと引き分けのないノックアウト戦を並べたりすることができませんでした。今は、部門とテストマッチの追加や編集のときに3つとも尋ね、大会のフォームでは尋ねません。最後の1つは、競技に世界ランキングがある場合にだけ尋ね、対象にならない部門はランキングのファイルに含まれません。[部門](../tournament-managers/standard-tournament/competitions.md)をご覧ください。([#341](https://github.com/CroquetScores/croquetscores.com/pull/341))

- **管理画面の大会一覧を、国、地域、競技で絞り込めます。** 選択はアドレスに入るので、絞り込んだ一覧へのリンクを共有でき、選べるのは一覧にあるものだけです。地域は国を選ぶと選べます。2026年11月より前の大会には地域がないため、地域を選ぶとそれらは表示されなくなり、公開の一覧にもその旨が出ます。([#354](https://github.com/CroquetScores/croquetscores.com/pull/354)、[#351](https://github.com/CroquetScores/croquetscores.com/pull/351))

- **世界ランキング担当者は競技ごとに1つの役割になりました。** アソシエーションクロッケーの担当者はアソシエーションクロッケーの大会を見て管理し、ゴルフクロッケーの担当者はゴルフクロッケーの大会を見て管理します。ご自分が運営または記録している大会は、競技にかかわらず一覧に残ります。([#348](https://github.com/CroquetScores/croquetscores.com/pull/348)、[#356](https://github.com/CroquetScores/croquetscores.com/pull/356))

- **ランキングタブは、競技を問わず、ファイルについて1つの段落で説明します。** その下にダウンロードのリンクがあります。[ランキング](../tournament-managers/standard-tournament/rankings.md)をご覧ください。([#346](https://github.com/CroquetScores/croquetscores.com/pull/346))

- **大会名をすべて小文字、またはすべて大文字にすることはできません。** メッセージも、これを決まりとして伝えるようになりました。([#345](https://github.com/CroquetScores/croquetscores.com/pull/345))

- **「外す」はごみ箱のアイコンになりました。** 運営者タブと記録係タブ、部門の選手、管理者のアカウントのページで、アーカイブと削除がすでにそうだったのと同じです。ポインターを合わせると今までどおり「外す」と表示され、スクリーンリーダーも「外す」と読み上げます。([#353](https://github.com/CroquetScores/croquetscores.com/pull/353))

- **すべての言語で言葉が新しくなりました。** 他の16言語のサイトの言葉をすべて書き直し、ヘルプもそれに合わせました。読者向けとアカウントのヘルプ、利用規約も、すべての言語で読めるようになりました。どれもまだネイティブの方に読んでいただいていませんので、読みにくいところがあればお知らせください。([#355](https://github.com/CroquetScores/croquetscores.com/pull/355)、[#349](https://github.com/CroquetScores/croquetscores.com/pull/349)、[#350](https://github.com/CroquetScores/croquetscores.com/pull/350))

- **裏側の変更。** 以前のサイトの取り込みで、一部のタイムゾーンと1つの大会の国が変わります（[#344](https://github.com/CroquetScores/croquetscores.com/pull/344)）。また、ダンプをサーバーに読み込み、読み取り用モデルを作る処理をスクリプトで行います（[#340](https://github.com/CroquetScores/croquetscores.com/pull/340)）。サイトはマージのたびではなく、パソコンまたは GitHub からスクリプトでデプロイします（[#352](https://github.com/CroquetScores/croquetscores.com/pull/352)）。

## 公開日 2026-10-19

大会を運営する方に関わる主な変更点です。詳しくは[大会運営者向けヘルプ](../tournament-managers/index.md)をご覧ください。

- **選手は大会に一度だけ登録します。** 以前のサイトでは、選手は部門ごとに追加していました。今は、大会の**選手**タブで追加、訂正、並べ替え、アーカイブを行い、そこで訂正した内容は、その選手が出ているすべての部門とすべての公開ページに反映されます。[選手](../tournament-managers/standard-tournament/players.md)をご覧ください。

- **選手は一覧から部門に入れます。** 部門のページで、ドロップダウンから大会の選手を選び、**選手を追加**を押します。ドロップダウンには、まだその部門にいない選手だけが表示されます。ノックアウト戦では、余った枠のために**Bye**も選べます。[部門に選手を登録する](../tournament-managers/standard-tournament/entering-players-in-a-competition.md)をご覧ください。

- **部門の追加はボタン1つです。** 別々だった新規ブロック戦、新規スイスドロー、新規ノックアウト戦のボタンに代わり、**部門を追加**を押します。ダイアログでは、名前と種類（ブロック戦、ノックアウト戦、スイスドロー）を尋ね、続いてその種類に必要なこと、つまり各試合の最大ゲーム数と、ノックアウト戦ではドローの枠数を尋ねます。ダイアログは開いたままなので、いくつかまとめて追加できます。部門の種類はあとから変更できません。アーカイブして、もう一度追加してください。[部門](../tournament-managers/standard-tournament/competitions.md)をご覧ください。

- **運営者のお知らせ：選手に伝えたいことには、実況の代わりにこちらを使います。** 形式、試合順の変更、昼食の時間などです。お知らせは大会の**お知らせ**タブで、タイトルと Markdown の説明文を付けて書き、追加する前にプレビューできます。選手は大会の公開「お知らせ」ページでお知らせを見られます。未読のお知らせには、開くまでアスタリスクが付き、大会のどのページの「お知らせ」セクションにも付きます。お知らせを編集すると、すでに読んだ全員に対して再び未読の印が付きます。[お知らせ](../tournament-managers/standard-tournament/notes.md)をご覧ください。

- **以前のサイトの大会の「お知らせ」は、サブタイトルになりました。** そこに書かれていた内容は大会のサブタイトルとして保たれ、これまでどおりすべての公開ページで大会名の下に表示されます。Markdown で書き、2000文字までです。どのページを見ていても読者に知ってほしいことに使います。大会の進行につれて変わる知らせには、お知らせを使ってください。
