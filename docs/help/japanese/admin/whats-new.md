# 大会運営者向けの新機能

## 公開日 2026-10-19

大会を運営する方に関わる主な変更点です。詳しくは[大会運営者向けヘルプ](../tournament-managers/index.md)をご覧ください。

- **選手は大会に一度だけ登録します。** 以前のサイトでは、選手は部門ごとに追加していました。今は、大会の**選手**タブで追加、訂正、並べ替え、アーカイブを行い、そこで訂正した内容は、その選手が出ているすべての部門とすべての公開ページに反映されます。[選手](../tournament-managers/standard-tournament/players.md)をご覧ください。
- **選手は一覧から部門に入れます。** 部門のページで、ドロップダウンから大会の選手を選び、**選手を追加**を押します。ドロップダウンには、まだその部門にいない選手だけが表示されます。ノックアウト戦では、余った枠のために**Bye**も選べます。[部門に選手を登録する](../tournament-managers/standard-tournament/entering-players-in-a-competition.md)をご覧ください。
- **部門の追加はボタン1つです。** 別々だった新規ブロック戦、新規スイスドロー、新規ノックアウト戦のボタンに代わり、**部門を追加**を押します。ダイアログでは、名前と種類（ブロック戦、ノックアウト戦、スイスドロー）を尋ね、続いてその種類に必要なこと、つまり各試合の最大ゲーム数と、ノックアウト戦ではドローの枠数を尋ねます。ダイアログは開いたままなので、いくつかまとめて追加できます。部門の種類はあとから変更できません。アーカイブして、もう一度追加してください。[部門](../tournament-managers/standard-tournament/competitions.md)をご覧ください。
- **運営者のお知らせ：選手に伝えたいことには、実況の代わりにこちらを使います。** 形式、試合順の変更、昼食の時間などです。お知らせは大会の**お知らせ**タブで、タイトルと Markdown の説明文を付けて書き、追加する前にプレビューできます。選手は大会の公開「お知らせ」ページでお知らせを見られます。未読のお知らせには、開くまでアスタリスクが付き、大会のどのページの「お知らせ」セクションにも付きます。お知らせを編集すると、すでに読んだ全員に対して再び未読の印が付きます。[お知らせ](../tournament-managers/standard-tournament/notes.md)をご覧ください。
- **以前のサイトの大会の「お知らせ」は、サブタイトルになりました。** そこに書かれていた内容は大会のサブタイトルとして保たれ、これまでどおりすべての公開ページで大会名の下に表示されます。Markdown で書き、2000文字までです。どのページを見ていても読者に知ってほしいことに使います。大会の進行につれて変わる知らせには、お知らせを使ってください。
