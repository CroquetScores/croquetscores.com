# 大会運営者・記録係・実況者向けの利用規約

このサイトに書き込むうえでの規約です。大会を入力する大会運営者、結果を入力する記録係、実況やそのコメントを書く実況者のいずれの場合にも当てはまります。登録するときと、実況を始めるたびに、同意をお願いします。この規約は、すべての閲覧者が同意する[利用規約](/terms-of-use)に加えて適用されます。

## 書いた内容はあなたの責任です

書いた内容はあなたの名前で公開され、あなた自身のものです。そこに書かれた意見はあなたの意見であり、サイトを運営する人の意見とは限りません。

## 結果

結果は実際に行われたとおりに入力し、誤りが分かったら訂正してください。選手、所属クラブ、世界ランキングは、結果に基づいています。

## 実況

実況は、大会で何が起きているかを読者に伝えるためのものです。祝辞や会話のための場ではありません。

## 禁止事項

何を書く場合でも、次のような内容は書かないでください。

- 暴力や憎悪をあおるおそれのあるもの、または人種、宗教、民族、性別、年齢、障害、性的指向を理由に誰かを辱めるもの。
- 人の行いではなく、その人自身を攻撃するもの。ボールを打つのであって、選手を打つのではありません。
- 法律に違反するもの。たとえば、コピーしてはならないものをコピーすること、他人の評判を傷つける虚偽を述べることなど。
- 宣伝、販売、勧誘をするもの、またはスパム。
- 不適切な内容へのリンク、または必要以上に多くのリンクを含むもの。
- 他人になりすますもの、または誰かの電話番号、住所、メールアドレスを載せるもの。
- 汚い言葉を含むもの、または大文字で書かれたもの。

## サイトができること

サイトを運営する人は、この規約に違反して書かれた内容を変更または削除することができ、違反を繰り返すアカウントを閉鎖することができます。

## 書かれた内容の報告

サイトでこの規約に違反するものを見つけたら、このページの下にあるアドレスへメールで報告してください。そのウェブアドレスを記し、書かれた内容を引用し、削除すべき理由を述べてください。報告はすべて読みますが、報告されたものがすべて削除されるとは限りません。

## 変更

この規約は変更されることがあります。このページにある規約が適用され、次に実況を始めるときに、改めて同意をお願いします。
