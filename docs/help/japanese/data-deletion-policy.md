# データ削除ポリシー

このサイトが保管しているあなたの情報を削除してもらう方法です。Facebook、Google、メールアドレスとパスワードのいずれでサインインしていても当てはまります。

## 削除してもらう方法

1. 削除したいアカウントに、いつもどおりサインインします。
2. [アカウントを削除](/account/forget-account)を開きます。アカウントのメニューやプロフィールからも開けます。
3. **リンクをメールで送る**を押します。ご本人であることを確かめるため、サイトはアカウント自身のメールアドレスにリンクを送ります。そのリンクを開くまでは何も削除されません。
4. メールに届いたリンクを開きます。リンクは 15 分間、1 回だけ使え、そのアカウントにサインインしている間だけ有効です。開くと、忘れさせるとはどういうことかが表示されます。
5. **アカウントを削除する**を押します。

サインインしていたすべての場所からサインアウトされ、そのアカウントには二度とサインインできません。

## 削除されるもの

名前とメールアドレスは、サイトが保管しているすべての場所で、永久に「Forgotten Account」と番号に置き換えられ、メールアドレスは誰のものでもない example.com のアドレスに置き換えられます。サイトを運営する人を含め、誰もそれを二度と読めません。あなたのアカウントに紐づけられた Google や Facebook のアカウントにも同じ処理を行い、アカウントとあなたを結びつけるものが何も残らないようにします。そのメールアドレスは、その後、新しいアカウントとして改めて登録できます。

## 残るもの

アカウントの識別子は残ります。これはアカウントのために作られたランダムな番号で、あなたが誰であるかは何も表しません。公開した内容は、その識別子とともに「Forgotten Account」と番号の名前で残ります。作成した大会、入力したスコア、書いたコメントです。これは試合の記録であり、その試合に参加した人たちにも権利があります。もはや、あなたが誰だったかは表しません。

削除する前に作られたサイトのコピー（バックアップなど）には、そのコピーが保管されている間、当時の内容がそのまま残っています。

## ご注意

- **Facebook の設定からアプリを削除しても、ここでは何も削除されません。** Facebook がサイトとこれ以上情報を共有しなくなるだけです。データを削除してもらうには、上の手順に従ってください。
- **取り消すことはできません。** そのため、確認を 2 回行います。
- **唯一の管理者は削除できません。** このサイトの唯一の管理者である場合は、先にほかの人へ管理者の役割を渡してください。
- **サインインできない場合は、**[パスワードをお忘れの方](/account/forgot-password)のページで新しいパスワードを設定し、サインインしてから上の手順に従ってください。Facebook や Google でサインインしていた場合は、その方法でサインインしてください。

サイトが何をなぜ保管しているかは、[プライバシーに関する説明](/privacy)にあります。
