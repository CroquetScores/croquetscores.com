# 世界ランキング担当者向けヘルプ

世界ランキング担当者は、1つまたは複数の競技の世界ランキングを担当します。管理画面では、サインインしている閲覧者なら誰でも使える機能がすべて使えます。大会を作成できますし、運営者または記録係に指定された大会は、[大会運営者向け](../tournament-managers/index.md)の説明のとおり、運営や記録ができます。このページでは、それに加えて何ができるかだけを説明します。対象は `/admin` の大会一覧と、別の年の同じ一覧である `/admin/2025`、`/admin/2024` などです。

## 担当する競技のすべての大会

一覧には、誰が運営しているかにかかわらず、担当する競技のすべての大会が並びます。ご自分が運営または記録している大会も含まれます。読み進めるには多すぎるので、以下のとおり一覧を絞り込めます。

表示される年は、それらの大会が始まる年と、ご自分の大会の年です。上部のタブから選ぶか、それ以外は**以前の年**から選ぶと、その年の一覧になります。`/admin` は今年です。

## 一覧を絞り込む

**新しい大会**の横に、**表示**というラベルの下に3つのボタンがあります。

- **運営者/記録係**は、ご自分が運営または記録している大会を一覧にします。
- **世界ランキング**は、世界ランキングの対象となる部門がある大会を一覧にします。
- **世界ランキング対象外**は、そのような部門がない大会を一覧にします。

オンのボタンにはチェックマークが付きます。大会は、それに当てはまるボタンのどれかがオンなら一覧に表示されます。そのため、どのボタンも大会を一覧に加えるだけで、減らすことはありません。最初は**運営者/記録係**と**世界ランキング**がオンで、**世界ランキング対象外**はオフです。ご自分が運営する大会と、ランキングの元になる大会から始まり、残りを見るには**世界ランキング対象外**を押します。

すべてのボタンをオフにすると、一覧は空になり、該当する大会がないと表示されます。ボタンは残るので、どれかをオンに戻せます。

ボタンの状態はページのアドレスに書き込まれます。そのため、戻るボタンで直前に押したボタンを取り消せますし、コピーしたアドレスは、そのときの一覧をそのまま表示します。ボタンは絞り込む一覧があるときだけ表示されるので、大会のない年には表示されません。

その下の**国**、**地域**、**競技**の一覧は、ボタンで残ったものをさらに絞り込みます。これは他の方と同じです。その一覧にあるものだけが選べるので、選んだ結果が空になることはありません。

## 大会でできること

ランキングだけを担当している大会の横には、一覧に**選手**だけが表示されます。これを押すと大会のページが開きます。そこでは、選手の世界ランキング用の名前を変更したり、運営者を確認して**運営者にメールする**で連絡したり、**ランキング**タブから世界ランキング用のゲームを受け取ったりできます。大会の変更、アーカイブ、スコアの入力はできません。それらは運営者と記録係の役目だからです。この種のアーカイブ済みの大会にはボタンがありませんが、大会名を押せばそのページが開きます。

ご自分が運営または記録している大会の横には、運営者や記録係に表示されるものと同じ、鉛筆（**編集**）とごみ箱（**アーカイブ**）の付いた**運営**、または**スコア**が表示されます。担当者であっても、これは変わりません。
