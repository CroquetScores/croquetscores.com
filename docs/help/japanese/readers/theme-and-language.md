# テーマと言語の選択

どちらの選択も各ページの最下部にあり、選んだ内容は記憶されるので、一度選べば済みます。

## テーマ

**テーマ**では**ライト**、**ダーク**、**システム**を選べます。選ぶまでは**システム**になっており、スマートフォンやパソコンの設定に従います。端末がダークならサイトもダーク、そうでなければライトになります。端末の設定にかかわらず、サイトをそのどちらかにしたいときは**ライト**または**ダーク**を選んでください。

## 言語

選ぶまでは、ブラウザが読めると伝えてくる言語のうち、サイトが対応している最初の言語で表示されます。どれも対応していなければ英語で表示されます。

別の言語を選ぶには、**言語**の一覧から選んで**変更**を押します。ページがその言語で表示し直され、以降のページも、今回もまた次回も、その言語で表示されます。一覧は、いま読んでいる言語が選ばれた状態で開きます。

このヘルプのページのうち、まだお使いの言語になっていないものは、表示されないのではなく、英語で表示されます。

## 選択が忘れられたとき

サイトは選択をそれぞれ Cookie に記憶します。Cookie を消去するブラウザや、保存しない設定のブラウザでは選択が忘れられ、もう一度選ぶことになります。サイトが保存するものについては[スクリプトと Cookie](scripting-and-cookies.md)をご覧ください。
