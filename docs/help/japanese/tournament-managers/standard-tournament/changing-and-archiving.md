# 大会の変更、アーカイブ、復元

## 大会の詳細の変更

管理画面の大会一覧で、その大会の**編集**を押します。フォームは大会を作成したときと同じもので、現在の内容が入っています。誤っている箇所を直して**大会を更新**を押します。

![大会の編集フォーム](../../../english/tournament-managers/standard-tournament/images/edit-tournament.png)

大会に選手か部門が1つでもあると、アーカイブ済みのものを含めて、形式をチームで行うものに変更できません。そちらには選手と部門の代わりにチームとテストマッチがあるからです。

名称を訂正しても大会のアドレスは変わらないので、誰かがすでに送ったリンクはそのまま使えます。アドレスが変わるのは開始日の年か競技が変わったときだけで、その場合は古いアドレスから新しいアドレスへ誘導されます。保存すると、大会が現在ある場所へ移動します。

大会を変更できるのは運営者だけです。記録係やそのほかの人には、フォームの代わりにその旨が表示されます。

## 大会の一覧

管理画面は1年分ずつ、今年から、新しい大会を先頭に一覧表示します。あなたが大会を持つ年は、濃い緑色のバーに新しい年から順にタブとして並びます。スマートフォンに収まらないほど多い場合、古い年は行の末尾のドロップダウンリストに入ります。年はアドレスに含まれるので、年にリンクできます。

![大会の一覧](../../../english/tournament-managers/standard-tournament/images/admin-list.png)

## 大会のアーカイブ

一覧の大会の**アーカイブ**は、その大会を脇に置きます。大会は取り消し線付きで、使用中の大会の後に引き続き一覧表示されますが、**復元**だけが表示されます。管理画面のページと公開ページは、復元されるまで閉じられます。アーカイブは確認を求めません。復元で元に戻せるからです。

![一覧のアーカイブ済みの大会](../../../english/tournament-managers/standard-tournament/images/admin-list-archived.png)
