# 選手

大会のページの**選手**タブでは、大会の選手を登録し、訂正し、並べ替え、除外します。大会で最初に行うのは選手の登録なので、ページはこのタブで開きます。

選手は大会にここで一度だけ登録します。各選手がどの部門に出場するかは、あとから各部門のページで、ここで登録した選手の中から選びます。[部門への選手の登録](entering-players-in-a-competition.md)を参照してください。

![選手タブ、選手が登録され1人がアーカイブ済み](images/players-tab.png)

## 選手の追加 {#add-a-player}

一覧の上にある**選手を追加**を押します。ページの上にダイアログが開きます。

![選手の追加ダイアログ、入力済み](images/add-player-dialog.png)

**名前**は必須です。すべてのページに表示される選手の名前で、3文字以上254文字以内です。1つの大会で2人の選手が同じ名前を持つことはできません。大文字と小文字の違いも区別されません。本当に同じ名前の選手が2人いる場合は、「Andrew Hobbs (2)」のように名前そのもので区別してください。

**代表**は選手が代表するもので、読者が言うとおりに書きます。「Canterbury Croquet Club」のようなクラブ、地域、国です。名前の後ろに括弧で表示されます。空のままでも構いません。

**国旗**は選手の名前のそばに表示される国旗です。なしのままでも構いません。ほとんどの選手はそうです。選手の所属と掲げる国旗は別に扱います。ある国のクラブに所属しながら、別の国の国旗を掲げる選手がいるからです。

**世界ランキングの選手名**は、世界ランキングでその選手が知られている名前です。世界ランキングが選手の一覧を持つ2つの競技、アソシエーションクロッケーとゴルフクロッケーの大会でだけ尋ねます。アメリカン6ウィケットの選手はランキングでも本名で知られているので、そこでは尋ねず、各選手の世界ランキングでの選手名は常にその選手の名前です。選手を追加している間は、入力する名前に追随します。ほとんどの選手はランキングでも本名で知られているからです。この項目に直接入力すると追随は止まります。空のままにすると、選手の名前として保存されます。

名前を入力すると、その文字で始まる、世界ランキングが知っている選手が候補として表示されるので、入力し切らなくても、ランキングの綴りどおりの名前を選べます。世界ランキングでの選手名のそばには、ランキングがその名前を知っていればチェックマークが、知らなければ疑問符が表示されます。綴りの誤りか、ランキングに載ったばかりの選手かもしれません。これは参考にすぎません。ランキングが知らない名前も、知っている名前と同じように保存されます。

**追加**を押します。選手が追加され、ダイアログがそう告げ、項目は次の選手のために空になり、カーソルは名前に戻ります。この方法で一覧全体を追加してから、**キャンセル**を押してダイアログを閉じます。キャンセルは、まだ追加していない内容を何も保存しません。

![選手を追加した後のダイアログ](images/add-player-dialog-added.png)

選手に「Bye」という名前は付けられません。ノックアウト戦の不戦勝はノックアウト戦そのものの中で、選手を登録する場所で追加するので、最初の単語が英語の「bye」である名前は受け付けられず、ダイアログがその理由を説明します。

## 選手をまとめて追加 {#adding-multiple-players}

一覧をまとめて追加するには、**選手を追加**の隣にある**選手をまとめて追加**を押します。ページの上にダイアログが開き、複数行のテキストを入力できるボックスが1つ表示されます。表計算ソフトから一覧をコピーして、ボックスに貼り付けることもできます。

**1行目は項目名です。** カンマまたはタブで区切り、**Name**と、**Representing**、**Flag**、**Handicap**、**WorldRankingPlayerName**のうち必要なものを、順序は自由に並べます。これらの名前は、サイトの言語にかかわらず英語で入力します。**Name**は必ず含めてください。**2行目以降は1人ずつの選手です。** 各項目の値を同じ順序、同じ区切りで並べます。ある項目に値がない選手は、その項目を空にし、カンマまたはタブは残します。たとえば、カンマで区切る場合は次のとおりです。

```
Name,Representing,Flag
Sam Someone,Canterbury Croquet Club,New Zealand
Alex Another,,England
```

- **名前、代表、世界ランキングの選手名**には、選手を1人ずつ追加するときと同じ規則が適用されます（[選手の追加](players.md#add-a-player)を参照）。名前は3文字以上254文字以内で、大文字と小文字の違いを問わず大会にすでにある名前は使えず、「Bye」も使えません。
- **国旗**は、国や地域の名前を、お使いの言語で、選手を追加ダイアログの一覧に表示されるとおりに書きます。たとえばニュージーランドです。
- **ハンディキャップ**は符号付きの数で、整数部は最大2桁、小数部は1桁までです。たとえば4、+4、-1.5です。
- **WorldRankingPlayerName**がない選手は、1人ずつ追加したときと同じように、その選手の名前で知られているものとして扱います。
- **カンマまたはタブ。** 表計算ソフトからコピーしたセルはタブで区切られ、手で入力した一覧はたいていカンマで区切られます。どちらでも構いません。1行目にタブがあれば一覧全体をタブで、なければカンマで読みます。
- 区切り文字を含む値は、表計算ソフトと同じように二重引用符で囲みます。カンマ区切りの一覧では「"Smith, John"」のようにします。値の中の引用符は2つ重ねて書きます。
- 各値の両端の空白は取り除かれ、何もない行は無視されます。
- 一覧に入れられる選手は最大500人です。残りは別の一覧で追加してください。

**追加**を押します。一覧全体を調べてからでないと何も保存されないので、誤りが1つでもある一覧では誰も追加されません。誤りはボックスの下に、その行ごとに示されます。1行目を1行目として数えます。最初の1つだけでなくすべての誤りが示され、入力した内容は残るので、そのまま直せます。一覧が保存されるとダイアログが閉じ、選手タブに新しい選手が、書いた順に並びます。次の選手のために開いたままになる**選手を追加**と違い、次はありません。一覧がその次だからです。

ダイアログのタイトルバーにある**?**から、このページに来られます。

## 選手の訂正 {#correcting-a-player}

選手の名前か、その**編集**を押すと、同じダイアログが「選手の編集」というタイトルでその選手について開きます。誤っている箇所を直して**保存**を押すと、変更が保存されてダイアログが閉じます。名前を訂正した選手は、それまでの世界ランキングでの選手名を保ちます。ランキングはその名前で選手を知っているからです。アメリカン6ウィケットでは、選手の世界ランキングでの選手名は常にその選手の名前なので、名前を訂正すればそれも訂正されます。

![選手の編集ダイアログ](images/edit-player-dialog.png)

ここで訂正した選手は、あらゆる場所で訂正されます。出場しているすべての部門と、すべての公開ページです。

## 選手の並べ替え

選手は大会の順序で一覧表示されます。これは部門に登録するときに候補として並ぶ順序であり、ノックアウト戦の組み合わせの順序でもあります。各行の末尾にある矢印の**上へ**と**下へ**で、選手を1つ移動します。最初の選手には上へが、最後の選手には下へが表示されません。

## 選手のアーカイブ {#archiving-a-player}

**アーカイブ**は選手を脇に置きます。誤って登録した選手や、大会全体から棄権した選手に使います。アーカイブ済みの選手は、取り消し線付きで、使用中の選手の後に**アーカイブ済みの選手**の下に一覧表示され、**復元**だけが表示されます。アーカイブ済みの選手はどの部門にも入らず、どの公開ページにも表示されません。

試合を1つでも行った選手はアーカイブできません。その試合の相手がいなくなってしまうからです。そのため、そのような選手にはアーカイブが表示されません。試合がすべてアーカイブ済みの選手はアーカイブできます。

どの部門にも入っていない選手のアーカイブは確認を求めません。復元すればすべて元に戻るからです。いずれかの部門に入っている選手のアーカイブは、先に確認を求めます。アーカイブすると、入っていたすべての部門から外れ、復元しても元には戻らないからです。

![部門に入っている選手をアーカイブする前の確認](images/archive-player-asks.png)
