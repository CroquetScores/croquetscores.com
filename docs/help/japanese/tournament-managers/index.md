# 大会運営者向けヘルプ

このサイトの大会は、運営者が管理画面から運営します。運営者とは、大会を作成した人と、その人があとから運営者に加えた人です。このガイドでは、サインインから、結果が一般に公開された大会になるまでの手順を説明します。

大会には2つの種類があり、それぞれにガイドがあります。各ガイドはそれだけで完結しているので、運営する大会のガイドだけを読めば十分です。

- [標準大会の運営](standard-tournament/index.md)：選手を一人ずつ登録し、ブロック戦、ノックアウト戦、スイスドローで行う大会。クラブの週末大会、オープン大会、選手権など。
- [チームで行う大会の運営](teams-tournament/index.md)：チームどうしで行う大会。2つのチームのテストマッチを、それぞれの選手どうしの対戦で構成します。テストシリーズ、州対抗シールド、世界チーム選手権など。

大会がどちらの種類になるかは、作成時の**形式**で決まります。前者は標準、後者はチーム戦、Eire Cup、Interstate Shield、GCワールドチーム選手権のいずれかです。
