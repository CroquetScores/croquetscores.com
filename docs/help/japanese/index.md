# ヘルプ

このサイトを使う方のための、使い方の説明です。

- [大会運営者向け](tournament-managers/index.md)：大会の作成から、選手が見るページまで、管理画面から大会を運営する方法。
- [閲覧する方](readers/index.md)：ブラウザで大会を読む方法。テーマと言語の選択から、サイトがブラウザに求めることまで。
- [アカウント](accounts/index.md)：登録、サインイン、パスワード、そしてアカウントの管理。
- [世界ランキング担当者向け](world-ranking-officers/index.md)：管理画面の大会一覧が、ご自分で運営する大会のほかに提供するもの。
