# Hjälp

Så använder du webbplatsen, skrivet för dem som använder den.

- [Turneringsledare](tournament-managers/index.md): att leda en turnering från administrationen, från att den skapas till de sidor som spelarna följer.
- [Läsare](readers/index.md): att läsa en turnering i en webbläsare, från att välja tema och språk till vad webbplatsen kräver av din webbläsare.
