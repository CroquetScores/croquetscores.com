# JavaScript och kakor

## Att läsa kräver ingetdera

Sidorna som visar en turnering, dess resultat, dess spelare och dess rankningar fungerar med JavaScript avstängt. Det gör också valet av tema och språk.

## Kakor

Webbplatsen sätter en kaka för att hålla dig inloggad, en för temat du valde, en för språket du valde och en för vad du har sagt om meddelanden om nyheter. De finns där för att webbplatsen ska göra det du bad om, och används inte för att följa dig. Om du aldrig loggar in eller väljer något finns det lite för dem att hålla. [Integritetssidan](../privacy.md) har allt som webbplatsen sparar.

En webbläsare som vägrar kakor kan ändå läsa en turnering. Den glömmer dina val vid varje besök, och den kan inte hålla dig inloggad.

## Att registrera sig kräver JavaScript

Att registrera sig är det enda stället där JavaScript behövs. Webbplatsen ber Googles reCAPTCHA skilja en person från ett program, och det körs som JavaScript i din webbläsare. Om JavaScript är avstängt när du öppnar registreringssidan skickas du till en sida som säger det, innan du har fyllt i något. Slå på JavaScript för den här webbplatsen och gå sedan **Tillbaka till registreringen**.

Att be om ett sätt att komma tillbaka till ett konto du inte kan logga in på kräver inte JavaScript.

Nästa: tillbaka till [Hjälp för läsare](index.md).
