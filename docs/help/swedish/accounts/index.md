# Hjälp för ditt konto

Du behöver inget konto för att läsa en turnering. Du behöver ett för att leda en turnering och för att skriva på webbplatsen. De här guiderna visar hur du har ett konto, från att registrera dig till att få det glömt.

- [Registrera dig och bekräfta din e-postadress](registering.md): de två steg som skapar ett konto, och vad du gör när e-postmeddelandet inte kommer.
- [Logga in](signing-in.md): med ett lösenord, med Google eller med Facebook, och vad du gör när du inte kan.
- [Lösenord](passwords.md): vad ett lösenord måste vara, råd om hur du väljer ett och hur webbplatsen kontrollerar det.
- [Ta hand om ditt konto](looking-after-your-account.md): ditt namn, din e-postadress och hur du får kontot glömt.

Varje guide fungerar för sig, så du kan läsa den du behöver.
