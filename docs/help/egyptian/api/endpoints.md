# نقاط وصول الـ API

كل عنوان تحت `/api/v0` على الموقع، وكل رد JSON. اللي بيسري على الكل، زي المفاتيح والحصص والأخطاء وإزاي تسأل بالرخيص، موجود في [المساعدة لمطوّري التطبيقات](index.md).

فيه نوعين، ولكل واحد صفحة:

- [نقاط وصول GET](get-endpoints.md) بتقرا: بطولات سنة، بطولة، مسابقة، ترتيبها وألعابها، الرياضات والأشكال والبلاد اللي البطولة ممكن تبقاها، لاعبين التصنيف العالمي وألعابهم، المفتاح يقدر يعمل إيه، وإيه اللي اتغيّر أو اتأرشف.
- [نقاط وصول POST](post-endpoints.md) بتغيّر حاجة: إنشاء بطولة ومسابقاتها ولاعبيها وفرقها وألعابها، ومين يقدر يديرها ويسجّل النتايج.
