# Die API se eindpunte

Elke adres is onder `/api/v0` op die webwerf, en elke antwoord is JSON. Wat vir almal geld, soos sleutels, kwotas, foute en hoe om goedkoop navraag te doen, staan in die [hulp vir toepassingontwikkelaars](index.md).

Daar is twee soorte, en 'n bladsy vir elk:

- [Die GET-eindpunte](get-endpoints.md) lees: 'n jaar se toernooie, 'n toernooi, 'n kompetisie, sy stand en spelle, wat 'n sleutel mag doen, en wat verander of geargiveer is.
- [Die POST-eindpunte](post-endpoints.md) verander iets: 'n toernooi maak, sy kompetisies, spelers, spanne en spelle, en wie dit mag bestuur en telling hou.
