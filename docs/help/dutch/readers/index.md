# Help voor lezers

Je hebt geen account nodig om de uitslagen van een toernooi te lezen. Deze handleidingen zijn voor iedereen die dat doet, in een browser op een telefoon, een tablet of een computer. Ze leggen uit hoe je de site naar je zin instelt en wat hij van je browser vraagt.

- [Het thema en de taal kiezen](theme-and-language.md): licht of donker, en de taal waarin de site tegen je praat.
- [Scripts en cookies](scripting-and-cookies.md): wat de site in je browser bewaart, en het ene onderdeel waarvoor scripts aan moeten staan.
