# 가입과 이메일 주소 확인

계정은 두 단계로 만들어져요. 먼저 이메일 주소를 알려 주고, 그다음 그 주소로 보낸 링크를 따라가서 내 주소임을 보여 주어요. 이름과 비밀번호는 두 번째 단계에서 물어봐요.

## 가입

**계정** 메뉴에서 **가입**을 누르세요. 페이지에서는 **이메일 주소**만 물어봐요. 사이트에 쓰는 글에 관한 **이용 약관에 동의합니다**를 체크하고 **가입**을 누르세요. **Google로 가입**이나 **Facebook으로 가입**을 눌러도 되고, 이 방법은 비밀번호가 필요 없어요. [로그인](signing-in.md)을 보세요.

가입하려면 이 사이트에서 스크립트가 켜져 있어야 해요. 사이트가 사람과 프로그램을 구별해야 하기 때문이에요. 스크립트가 꺼져 있으면 아무것도 채우기 전에 그렇다고 알려 줘요. [스크립트와 쿠키](../readers/scripting-and-cookies.md)에 더 자세히 나와 있어요.

다음 페이지에는 **이메일을 확인해 주세요**라고 나와요. 주소가 누구의 것이든 똑같이 알려 주기 때문에, 어떤 주소에 계정이 있는지 낯선 사람에게 알려 주지 않아요. 몇 분이 지나도 아무것도 오지 않으면 정크 메일함이나 스팸함을 살펴보세요.

## 확인하기

이메일에 있는 링크를 따라가세요. 링크는 바로 확인해 주지 않고 양식을 열어요. 메일 시스템이 이메일 속 링크를 검사하려고 먼저 따라가 보기 때문이고, 주소는 이메일을 읽은 사람만 확인해야 하기 때문이에요.

양식에서는 **이름**과, 두 번 입력하는 **비밀번호**를 물어봐요. 두 번째는 **비밀번호 확인**이에요. 비밀번호가 갖춰야 할 조건은 [비밀번호](passwords.md)에 나와 있어요. **이메일 주소 확인**을 누르세요.

링크는 다른 기기에서 열 때가 많아서, 확인해도 로그인되지는 않아요. 이메일 주소가 확인되었다고 알려 주고 **로그인**으로 안내해 줘요.

## 링크가 더 이상 작동하지 않을 때

링크는 24시간 동안 작동해요. 그 뒤에는 만료되었다고 나오고, **새 링크 보내기**를 누르면 같은 주소로 새 링크를 보내 줘요. 새 링크는 한 시간에 세 번까지 요청할 수 있고, 가입할 때 보내는 이메일도 같은 한도에 포함돼요.

링크가 바뀌었다거나 하는 다른 이유로 작동하지 않으면 더 이상 작동하지 않는다고만 나와요. 이미 확인했다면 그렇다고 알려 주고 로그인하라고 안내해 줘요.

## 가입한 사람이 내가 아닐 때

누구나 가입 페이지에 아무 주소나 입력할 수 있어요. 요청하지 않은 이메일이 도착했다면 무시하세요. 링크를 따라가 양식을 채우지 않으면 어떤 계정도 확인되지 않아요.
