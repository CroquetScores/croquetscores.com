# 계정 도움말

대회를 읽는 데는 계정이 필요 없어요. 대회를 운영하거나 사이트에 글을 쓰려면 계정이 필요해요. 이 안내서들은 가입부터 계정을 잊기까지, 계정을 갖는 방법을 설명해요.

- [가입과 이메일 주소 확인](registering.md): 계정을 만드는 두 단계, 그리고 이메일이 오지 않을 때 해야 할 일이에요.
- [로그인](signing-in.md): 비밀번호나 Google, Facebook으로 로그인하는 방법, 그리고 로그인할 수 없을 때 해야 할 일이에요.
- [비밀번호](passwords.md): 비밀번호가 갖춰야 할 조건, 비밀번호를 고르는 요령, 그리고 사이트가 비밀번호를 확인하는 방법이에요.
- [계정 돌보기](looking-after-your-account.md): 이름, 이메일 주소, 그리고 계정을 잊게 하는 방법이에요.

각 안내서는 따로 읽어도 되니, 필요한 것만 읽으세요.
