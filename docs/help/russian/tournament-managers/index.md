# Справка для управляющих турниров

Турниром на этом сайте управляют из раздела администрирования его управляющие: тот, кто его создал, и все, кого он с тех пор сделал управляющими. Эти руководства рассказывают, как это делается — от входа на сайт до турнира, результаты которого открыты публике.

Турниры бывают двух видов, и для каждого есть своё руководство. Каждое руководство самостоятельно, так что можно прочитать то, что относится к вашему турниру, и больше ничего.

- [Проведение стандартного турнира](standard-tournament/index.md): турнир между игроками, заявленными по одному, в группах, сетках на вылет и по швейцарской системе. Клубные выходные, открытый турнир, чемпионат.
- [Проведение командного турнира](teams-tournament/index.md): турнир между командами, в виде тестов между двумя сторонами, составленных из матчей между их игроками. Тестовая серия, межштатный щит, командный чемпионат мира.

К какому виду относится турнир, решает его **Формат** при создании: Стандартный для первого, а Командный, Eire Cup, Interstate Shield или GC World Team Championship — для второго.
