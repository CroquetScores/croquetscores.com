# Рейтинги

Если соревнование учитывается в мировом рейтинге, его результаты отправляются в рейтинг в виде файла, который сайт составляет из введённого вами. Получить его можно на вкладке **Рейтинги**.

## Вкладка

Откройте страницу турнира и выберите **Рейтинги** — последнюю из её вкладок. Там сказано, что это за файл: текстовый файл для ассоциационного крокета, электронная таблица для гольф-крокета и американского крокета на 6 воротах. Там сказано, что остаётся сделать вручную и что затем файл нужно отправить ответственным за мировой рейтинг. Ниже находится кнопка **Скачать рейтинги**, которая сохраняет файл. Она есть ещё до того, как введён хоть один результат, и до тех пор отдаёт файл, в котором ничего нет.

Вкладка есть только на странице турнира по виду спорта, у которого есть мировой рейтинг, и только для его организаторов: секретарю она не предлагается. Сам файл находится по собственному адресу турнира с добавленным `/rankings`, как `/2026/ac/spring-open/rankings`; сайт всегда давал именно этот адрес, и открыть его может любой, у кого он есть.

## Что в файле

В нём есть каждый введённый и не архивированный результат, в том порядке, в каком он был введён, включая снятый результат и результаты снявшегося игрока. Архивированного результата в нём нет. Матч, выигранный по баю или по неявке, не игрался, поэтому строки у него нет.

Игрок указан под своим именем в мировом рейтинге, которое совпадает с его именем, если ему не дали другого.

Для **ассоциационного крокета** есть раздел для каждого соревнования, в котором есть результат: его событие, его даты, его победитель, были ли это матчи или одиночные партии, и пронумерованная строка для каждого результата, например «1 Sam Someone beat Alex Another +9». Результат — это воротца победителя минус воротца проигравшего, с плюсом, если победитель набрал больше, и за ним число peel. Матч сетки плей-офф — одна строка, в которой по очереди указан результат каждой партии. Сайт может только предположить, кто выиграл соревнование, поэтому проверьте строку **Winner** в каждом разделе (в файле она написана по-английски) и исправьте её, прежде чем отправлять файл дальше.

Для **гольф-крокета и американского крокета на 6 воротах** есть электронная таблица: название турнира, его дни и сколько в нём партий, затем пронумерованная строка для каждой партии, с фамилией и именем победителя, словом «beat», фамилией и именем проигравшего и двумя результатами. Каждая партия матча сетки плей-офф — отдельная строка. Под последней строка **Tournament winner:** (в файле она тоже по-английски) оставлена пустой, чтобы вы её заполнили.

## Когда файла нет

У турнира, ни одно соревнование которого не учитывается в мировом рейтинге, файла нет. Если открыть его адрес рейтингов, появится страница, которая говорит об этом и объясняет почему: у его вида спорта нет мирового рейтинга или ни одно из его соревнований не учитывается, потому что каждое играется с форой, допускает ничьи или отмечено как не учитываемое. Это задаётся, когда добавляют каждое соревнование, и меняется его кнопкой **Изменить**. В файле только те соревнования, которые учитываются.
