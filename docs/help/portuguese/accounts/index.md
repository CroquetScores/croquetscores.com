# Ajuda para a sua conta

Você não precisa de uma conta para ler um torneio. Precisa de uma para administrar um torneio e para escrever no site. Estes guias explicam como ter uma conta, do cadastro até esquecê-la.

- [Cadastrar-se e confirmar o seu endereço de e-mail](registering.md): os dois passos que criam uma conta e o que fazer quando o e-mail não chega.
- [Entrar](signing-in.md): com uma senha ou com o Google, e o que fazer quando não é possível.
- [Senhas](passwords.md): o que uma senha precisa ter, conselhos para escolher uma e como o site a verifica.
- [Cuidando da sua conta](looking-after-your-account.md): o seu nome, o seu endereço de e-mail e como fazer a conta ser esquecida.

Cada guia se basta, então você pode ler o que precisar.
