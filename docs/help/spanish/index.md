# Ayuda

Cómo usar el sitio, para quienes lo usan.

- [Gestores de torneos](tournament-managers/index.md): llevar un torneo desde la administración, desde crearlo hasta las páginas que siguen sus jugadores.
- [Lectores](readers/index.md): leer un torneo en un navegador, desde elegir el tema y el idioma hasta lo que el sitio necesita de tu navegador.
- [Tu cuenta](accounts/index.md): registrarse, iniciar sesión, contraseñas y cuidar una cuenta.
- [Responsables del ranking mundial](world-ranking-officers/index.md): lo que la lista de torneos de la administración te da además de los torneos que llevas.
