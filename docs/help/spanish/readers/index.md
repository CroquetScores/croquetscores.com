# Ayuda para lectores

No necesitas una cuenta para leer los resultados de un torneo, y estas guías son para quien lo hace, en un navegador de un móvil, una tableta o un ordenador. Explican cómo tener el sitio como te gusta leerlo y qué necesita de tu navegador.

- [Elegir el tema y el idioma](theme-and-language.md): claro u oscuro, y el idioma en que te habla el sitio.
- [Scripts y cookies](scripting-and-cookies.md): qué guarda el sitio en tu navegador y lo único que necesita tener los scripts activados.
