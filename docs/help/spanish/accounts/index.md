# Ayuda para tu cuenta

No necesitas una cuenta para leer un torneo. La necesitas para llevar un torneo y para escribir en el sitio. Estas guías explican cómo tener una, desde registrarte hasta hacer que se olvide.

- [Registrarse y confirmar tu dirección de correo electrónico](registering.md): los dos pasos que forman una cuenta y qué hacer cuando el correo no llega.
- [Iniciar sesión](signing-in.md): con contraseña, con Google o con Facebook, y qué hacer cuando no puedes.
- [Contraseñas](passwords.md): cómo tiene que ser una contraseña, consejos para elegirla y cómo la comprueba el sitio.
- [Cuidar tu cuenta](looking-after-your-account.md): tu nombre, tu dirección de correo electrónico y cómo hacer que se olvide la cuenta.

Cada guía se entiende por sí sola, así que puedes leer la que necesites.
