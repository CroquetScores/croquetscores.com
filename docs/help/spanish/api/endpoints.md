# Los puntos finales de la API

Cada dirección está bajo `/api/v1` en el sitio, y cada respuesta es JSON. Lo que vale para todas, como las claves, los límites, los errores y cómo preguntar con economía, está en la [ayuda para desarrolladores de aplicaciones](index.md).

Hay dos clases, y una página para cada una:

- Los [puntos finales GET](get-endpoints.md) leen: los torneos de un año, un torneo, una competición, su clasificación y sus partidas, los deportes, formatos y países que puede ser un torneo, los jugadores del ranking mundial y sus partidas, lo que puede hacer una clave y lo que cambió o se archivó.
- [Los puntos finales POST](post-endpoints.md) cambian algo: crear un torneo, sus competiciones, jugadores, equipos y partidas, y quién puede gestionarlo y anotar los resultados.
