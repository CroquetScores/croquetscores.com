# Palīdzība

Kā lietot vietni, tiem, kas to lieto.

- [Lasītāji](readers/index.md): turnīra lasīšana pārlūkā, sākot ar motīva un valodas izvēli un beidzot ar to, ko vietne prasa no jūsu pārlūka.
- [Jūsu konts](accounts/index.md): reģistrēšanās, pierakstīšanās, paroles un konta kopšana.
- [Turnīru pārvaldnieki](tournament-managers/index.md): turnīra vadīšana administrēšanas sadaļā, no tā izveides līdz lapām, ko seko tā spēlētāji.
- [Pasaules ranga atbildīgie](world-ranking-officers/index.md): ko turnīru saraksts administrēšanas sadaļā un turnīra cilne Rangi jums dod papildus turnīriem, ko vadāt.
