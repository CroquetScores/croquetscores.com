# API galapunkti

Katra adrese atrodas zem `/api/v0` vietnē, un katra atbilde ir JSON. Kas attiecas uz visām, piemēram, atslēgas, limiti, kļūdas un lēta pieprasīšana, ir rakstīts [palīdzībā lietotņu izstrādātājiem](index.md).

Ir divi veidi, un katram sava lapa:

- [GET galapunkti](get-endpoints.md) lasa: gada turnīrus, turnīru, sacensības, to kārtību un partijas, ko drīkst atslēga un kas mainījies vai arhivēts.
- [POST galapunkti](post-endpoints.md) kaut ko maina: izveido turnīru, tā sacensības, spēlētājus, komandas un partijas, un nosaka, kas to drīkst pārvaldīt un ievadīt rezultātus.
