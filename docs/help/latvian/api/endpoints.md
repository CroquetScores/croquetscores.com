# API galapunkti

Katra adrese atrodas zem `/api/v1` vietnē, un katra atbilde ir JSON. Kas attiecas uz visām, piemēram, atslēgas, limiti, kļūdas un lēta pieprasīšana, ir rakstīts [palīdzībā lietotņu izstrādātājiem](index.md).

Ir divi veidi, un katram sava lapa:

- [GET galapunkti](get-endpoints.md) lasa: viena gada turnīrus, turnīru, sacensību grupu, tās tabulu un partijas, sporta veidus, formātus un valstis, kas var būt turnīram, pasaules ranga spēlētājus un viņu partijas, ko atslēga drīkst darīt un kas ir mainījies vai arhivēts.
- [POST galapunkti](post-endpoints.md) kaut ko maina: izveido turnīru, tā sacensības, spēlētājus, komandas un partijas, un nosaka, kas to drīkst pārvaldīt un ievadīt rezultātus.
