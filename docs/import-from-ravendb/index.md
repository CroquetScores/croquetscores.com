# Import from RavenDB

What the import from the old sites, `npm run import:ravendb`, wrote down as it ran. The first two are written afresh by every import, which deletes them first.

- [Import corrections](import-corrections.md): what the import corrected of what the old sites kept, each with where it is on the new site and the old.
- [Accepted import errors](accepted-import-errors.md): what the import accepted from the old sites rather than keeping as an error, each with where it is on the new site and the old.
- [Missing tournaments](missing-tournaments.md): the old sites' documents that refer to a tournament document that does not exist.
